# Design

## Context

`enrichCurrentPullback` 把回撤用 `splitPullbackAtLow` 剥成 `completed`（摆动高点→真低点，拆形态）与 `inProgress`（真低点→今，不拆，只取 `bounceExtreme` 给联合形 XX/Z 用）。`renderPullbackNarrative` 对 `completed` 的 `rankedPatterns` 列"单锯齿/平台形 a-b-c"并固定写"走完即到头，守住结构线恢复上行"。引擎没有任何地方把 `completed` 整段当作一个浪、把反弹当作 b/x。

书依据（epub 仅第 1~7 章）：平台形 b 运行总量 70%~2 倍 a（§5.1/§5.4）；联合形 x ≥70% w（§1.7）、x 运行总量 ≤1.5×w（§6.11 对联合形 x 的限制，代码 `sideways-double.ratio.x-le-1.5w-gross` 已实现）；平台形 c 与 a 终点关系（§5.4）；平台形 c 比例 规则 0.618/1/1.236、扩散 1.236~1.618（§5.4）；双锯齿 x 通常回撤 w 价格 30%~70%（§7）。联合形 y 的下限/目标在第 8 章，不在本书内。

## Goals / Non-Goals

**Goals:**
- 对 `completed` 整段输出"高一级读法"：70% 线、规则型/联合形/平台形上限、三态文字、平台形 c 目标。
- 把"走完即到头 / 守住结构线仍有上攻动力"改成有条件表述，并把单锯齿/平台形 a-b-c 降为"整段内部结构"。
- 区分联合形 XX 对 Y 的 70% 线与整段 70% 线。

**Non-Goals:**
- 不拆 b/x 浪内部、不判 b 是否三波（只在文字里写条件）。
- 不给联合形 y 的下限与目标。
- 不改主计数树、轴②/③、`zwaveProjection`、既有联合形 W-X-Y-XX-Z 读法。

## Decisions

1. **纯算术函数 `buildHigherDegreeReading`**，输入 `{extreme, trueLow, bounceExtreme, completed, inProgress, patterns, combinationReading}`，输出 JSON 友好对象 `narrative.higherDegree`；渲染只读该对象。这样可离线单测，不依赖取数。
2. **运行总量 G** = 摆动高点 − a 终点。`completed` 内摆动高点是最高枢轴、真低点是其后最低枢轴，二者即整段最高/最低，G 无需再查 K 线。
3. **a 终点的取法（状态③）**：`inProgress` 只有真低点本身（尚无反弹）时，说明刚创新低；取 `completed` 里"创新低的低点序列"中倒数第二个为 a 终点（此前的低点记录），b 最高取其后至真低点之间的最高枢轴。找不到则 a 终点即真低点，按状态①处理（反弹尚未展开）。有反弹时 a 终点就是真低点。
4. **状态判定**：反弹最高价 `bh` 来自枢轴（含末端 provisional 枢轴，枢轴价即该段高/低价）。`bh < line70` → ①；`bh ≥ line70` → ②；a 终点被此后的新低跌破（决策 3 的情形）→ ③。
5. **a 内部必须有调整浪读法**：`rankedPatterns` 里剔除含"三角"的标签后非空才输出；否则整节不输出。不新增拆解。
6. **平台形 c 目标**：仅状态②。`bh ≤ 摆动高点` → 规则型 0.618/1/1.236×G；`bh > 摆动高点` → 扩散型 1.236~1.618×G；起点用 `bh`（暂定，标注随反弹高点平移）。`bh > 平台形上限` → 读法作废，不给目标；`bh > 联合形上限` → 联合形被排除。联合形不给目标。
7. **文字措辞**：不断言"c 必须跌破 a 终点"，列出三种平台形子类对 a 终点的关系；明确"守住结构线不是回撤结束的证据"。
8. **两条 70% 线**：当 `combinationReading` 存在且其 Y 浪起止已知，则 `lineXX = trueLow + 0.7×|Y|`；与 `line70` 价位不同时，在正文以一句话区分基准并指出 `bh` 位于两线之间时哪个已过、哪个未过。
9. **向后兼容**：`nr.higherDegree` 缺失（旧测试手工构造的叙述对象、整段无调整浪读法）时，`renderPullbackNarrative` 保持原文不变，既有测试与 golden 不受影响。

## Risks / Trade-offs

- 反弹一旦越过摆动高点，`splitPullbackAtLow` 会把新高当作摆动高点，回撤叙述改从新高量起，所以"扩散 / 顺势型"（b 越过 a 起点）在真实流程里只会以前瞻文字（状态①的分支说明）出现，状态②的扩散型分支只能由手工构造的 split 触发；该分支保留是为了在 split 口径将来变化时仍然正确，测试用手工 split 覆盖。
- 状态③依赖枢轴序列的"创新低记录"，在枢轴很稀疏时可能找不到 a 终点，此时退回状态①文字（保守）。
- 70% 线用的是整段运行总量；若 a/w 内部是平台形且起终点价差小于运行总量（书§5.4），本实现 G 取枢轴最高-最低，等同运行总量，不会偏差。
- 分级失效线给出的是价位排除关系，不能替代"b 须为三波"的结构判断；文字已注明，但引擎不验证。
- `pullback-narrative-anchors` 也改叙述正文；本变更只在 `higherDegree` 存在时才改写两处措辞，合并冲突面小。
