## Context

`analyze-wave-tree.js` 的 Markdown 报告由多轮 change 逐节叠加而成，`renderMarkdownReport` 顺序拼接六个来源：`renderRankedCounts`（数法排名）、`renderCurrentWaveStructures`（当前进行浪 T1-T4 表）、`renderMultiDegree`（结论：父级候选=大级别 + a/b/c=小级别）、`renderAssessment`（现状研判 ①②③）、回撤叙述、`renderNarrative`（大白话版：一句话大局 / 拆成几大段 / 现在走到哪 / 接下来可能到哪 / 时间窗）。

现状（golden 实测约 266 行）三类重复：
- **当前反弹**同一段 `spanLast→ext→now` 被四套标签各表述一次：`T1-T4`(currentWaveStructures)、`a-b-c`(deriveCurrentInternal 小级别)、`XX·B·三浪`(bounceHyp 现状研判①)、`锯齿`(inProgressStruct 大白话)。且 `a-b-c` 与 `w-x-y` 同名不同级别，读者易误判"a 应是 5 浪"。
- **目标价 / 失效点**散落 5 处（数法排名投影、当前进行浪投影、父级候选目标价、小级别分水岭、接下来可能到哪）。
- **转折时间窗**在 `现状研判③` 与大白话 `可能的转折时间窗` 近乎逐字重复。

各来源 change 的 `_tree.json` 序列化字段（`serialize*`）是稳定契约，下游按字段消费；重构必须只动呈现层。

## Goals / Non-Goals

**Goals:**
- 报告按**三条主题轴**组织，每主题**单一权威呈现**：①大跌形态 ②当前反弹结构 ③投影与时间。
- 消除四套标签对同一段反弹的重复；统一为**一套主标签 + 明确层级归属**（a-b-c 与 w-x-y 的从属关系写清）。
- 目标价/失效点/时间窗收敛到轴③一处；其余节引用而不重列。
- 「大白话版」降为 TL;DR（结论 + 指路），不再整体复述。
- 行数显著下降（目标 <150 行量级），且信息不丢失（只去重、不删信息维度）。

**Non-Goals:**
- 不改数法引擎、评分、树构建、可判定性闸门、框架 A/B 逻辑。
- 不改任何 `serialize*` 输出与 `_tree.json` 字段（下游契约冻结）。
- 不新增分析维度或投影算法；仅重排既有内容的呈现。
- 不做 HTML/其他格式，仅 Markdown。

## Decisions

### D1：以「三轴」为顶层骨架，逐节归位而非重写
新 `renderMarkdownReport` 顺序：
```
# 分析报告（元信息）
# 现状研判（TL;DR：一句话结论 + 失效点，最先给）
# 轴① 大跌走完了什么形态     ← renderRankedCounts 为权威；父级候选并入为"它在更大结构里的角色"子块
# 轴② 当前反弹是什么结构     ← renderCurrentWaveStructures(T1-T4) 为权威；小级别 a/b/c、bounceHyp 收敛为导读
# 轴③ 接下来往哪、何时       ← 目标价/失效点/斐波时间窗集中；时间窗只出一次
<details> 技术细节（树 + 进行中结构，保留）
```
每个 render 函数保留但**改为产出"归位后的片段"**：删除其内部与他轴重复的段落，必要时输出一句"详见轴X"。不重写引擎侧派生。

**Alternatives**：整体重写单一 render（弃：丢失各函数已验证的措辞与 JSON 同源点，回归风险大）；仅加锚点链接不删内容（弃：解决不了"读了很乱"的根因）。

### D2：标签统一——父级=联合调整时，小级别 `a/b/c` 改标 `w/x/y`
在轴②权威表内，若父级候选主选为「联合调整(w-x-y)」，当前段内部记法直接用 `w/x/y`（对应 deriveCurrentInternal 已有的 `altLabelNote`），并对"整段反弹"这一外层单位与"反弹内部锯齿"这一内层单位显式标注级别，消除"a 该不该是 5 浪"的歧义。纯呈现映射，不改 `deriveCurrentInternal` 的数据。

### D3：大白话版降级为 TL;DR
`renderNarrative` 仅保留「一句话大局」+「一句当前处境」+「指向轴②/轴③」。删除 `拆成几大段`、`现在走到哪了`（内部拆解）、`接下来可能到哪`、`可能的转折时间窗`——这些内容已在三轴中权威呈现。

### D4：金标准断言改为"主题存在"而非"旧标题字面"
测试用例（含"两节并存""含某标题"）改为断言：三轴主题各出现一次、关键数字（失效点/主选形态/投影）仍在、且**不再出现重复节**（例如时间窗标题全文仅 1 次）。

## Risks / Trade-offs

- [删节导致信息丢失] → 重构前先对 golden 报告做"信息清单"（每个数字/结论的出处），逐项确认在新结构中仍有唯一落点后才删旧段。
- [golden 快照大面积改动、掩盖真实回归] → 断言改为语义级（主题/数字存在性、重复计数=1），而非整段文本快照；`serialize*` 输出加一条"零改动"回归断言锁死数据层未被误动。
- [下游按旧节标题解析文本] → proposal 已标 BREAKING（仅呈现层）；`_tree.json` 不变，建议下游改用 JSON 而非解析 Markdown。
- [父级=平台/之字（非联合）时 D2 映射不适用] → D2 仅在主选=联合调整时切换 w/x/y，其余沿用 a-b-c 并标明其为该形态的正式记法。
