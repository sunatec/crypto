## Why

Markdown 报告经多轮 change 累积（数法排名 / 当前进行浪 / 结论·父级候选 / 现状研判 / 大白话版各自新开顶层节），已膨胀到约 266 行，且**同一件事被换标签重复呈现**：当前反弹被 T1-T4、a-b-c、XX·B·三浪、锯齿四套字母系统各讲一遍；目标价与失效点散落 5 节；转折时间窗几乎逐字重复 2 节；「大白话版」整体复述上文全部内容。读者需反复对齐「这说的还是那段吗」，认知负担高。每个来源 change 的 design 都写了"旧节可精简/指向新表"，但精简步骤基本未落地。

## What Changes

- 报告按**三条主题轴**重组，每个主题只在**一处权威呈现**：
  - **轴①「大跌是什么形态」**：合并 `数法排名` 与大白话 `一句话大局/拆成几大段`；父级候选（`大级别`）作为"整段在更大结构里的角色"保留但**指向轴①、不重列大跌形态**。
  - **轴②「当前反弹是什么结构」**：`当前进行浪`(T1-T4) 为唯一权威表；`小级别 a/b/c`、`现状研判①`、大白话 `现在走到哪了` 收敛为**对该表的一句话导读或删除**；统一标签口径（明确 a-b-c 与 w-x-y 的层级归属，消除同名歧义）。
  - **轴③「接下来往哪 + 何时」**：目标价 / 失效点 / 斐波时间窗集中于此；删除 `现状研判③` 与 `可能的转折时间窗` 之一（二者重复）。
- 「大白话版」由"完整第二遍复述"降级为**纯结论 + 指路**（TL;DR），不再重述细节。
- **BREAKING（仅呈现层）**：Markdown 报告的节标题与顺序变化；下游若按旧节标题解析文本会受影响。
- **不改动**：数法引擎 / 评分 / 树构建 / JSON 序列化字段（`_tree.json` 保持稳定），仅重构 `render*` 呈现函数。
