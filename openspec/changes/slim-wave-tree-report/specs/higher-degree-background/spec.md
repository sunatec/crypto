## ADDED Requirements

### Requirement: 默认报告的大级别背景只出一段大白话

未传入 `--verbose` 时（任何主周期），md 中的“大级别背景（周线/月线）”与“顶层读法（自价格 0，周线）”两节 MUST 合并为一节“大级别背景（一句话）”，用不含术语的一段话说明：

- 前面那段大涨/大跌的起止价与年月，以及它途中最深一次回调的百分比；
- 这轮走势（窗口结构 S→E）的起止价与幅度；
- 据此判断：比那次回调更深 → 那段大概率已走完、现处更大一级调整，之后的走势要么是大调整中途的反弹/回落，要么是新一轮行情的开始；没超过 → 那段可能还没走完，这轮更像它中途的回调；价差与百分比口径结论不一致 → 暂不判断。

这一节 MUST NOT 出现 §3.3、级别阶梯表、月线摆动列表、扎针、顶层读法类别表与排除计数等内容。父级角色表下方的“…，顶层：…”逐条佐证与“S 为历史最高价……展示 N 级前段证据”一句 MUST 只在 `--verbose` 下输出。

传入 `--verbose` 时 MUST 按原样完整输出两节及上述佐证。`_tree.json` 中的 `background` 和 `topLevel` MUST 保持完整、不受影响。“报告声明数浪范围”一段 MUST 保留。

#### Scenario: 日线报告

- **WHEN** 以 `--tf 1d` 运行、未传 `--verbose`，前段 49000→126199.63 途中最深回调 32%，窗口下跌 126199.63→57800.19 跌 54%
- **THEN** md 的大级别背景为一段话：“前面那段大上涨 49000→126199.63（2024-08 至 2025-10），途中最深一次回调 32%；这轮下跌 126199.63→57800.19 跌了 54%，比那次回调更深——那段大上涨大概率已经走完……”
- **AND** md 中不出现“月线主要摆动”、级别阶梯表、“## 顶层读法”和“，顶层：”
- **AND** `_tree.json` 中的 `background` 和 `topLevel` 与改动前逐字段一致

#### Scenario: verbose 恢复全文

- **WHEN** 带 `--verbose` 运行
- **THEN** md 含“## 大级别背景（周线/月线）”全文、“## 顶层读法（自价格 0，周线）”全文和父级表下的“，顶层：”佐证
