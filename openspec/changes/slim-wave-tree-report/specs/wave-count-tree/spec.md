## ADDED Requirements

### Requirement: 轴③ 以价位梯子集中呈现全部点位

轴③ MUST 用一张按价格从高到低排列的价位梯子，呈现报告涉及的全部关键价位，包括：各情景下一腿目标、整段回撤位、进行中腿的回撤位、阻力/支撑、窗口区间极值（S）、现价和失效位。每档 MUST 写明含义及所属情景（如“情景 1”“情景 1、2 共振”）。价差在 0.03% 以内的档位 MUST 合并为一档，并列出全部含义。

同一价位在梯子里 MUST 只出现一次。报告其它位置引用这个价位时，MUST 只写数字或档名，不得再给出带倍数的完整梯度。斐波时间窗和“走完之后（续行浪目标）”MUST 跟在梯子后面，各出现一次。

X/B 情景的反弹 MUST 在现价那一档写明“X 已回撤 W 的 N%”。如果 X 浪幅度上限（双锯齿 x < W 的 100% 等）落在梯子范围内，MUST 把对应价位列为一档，并写明越过之后排除哪种读法。

#### Scenario: 窗口高点作为 X 上限列入梯子

- **WHEN** 主选为 X 连接浪，现价 78462，W 为 78878.01→75736.38，X 的反弹起点为 75736.38
- **THEN** 梯子包含 78878.01 一档，标注“X 上限（x < W 的 100%，越过则双锯齿 x 读法失效）；窗口最高”
- **AND** 现价一档写明“X 已回撤 W 的 87%”

#### Scenario: 回撤位全报告只出一次

- **WHEN** 报告存在进行中腿，回撤位为 0.382/0.5/0.618 → 77236.65 / 76950.19 / 76663.73
- **THEN** 这组带倍数的回撤位在 md 中只出现在轴③ 梯子里
- **AND** 轴① 的“当前在哪”和轴② 不再列出这组带倍数的梯度

#### Scenario: 原散落小节并入梯子

- **WHEN** 报告渲染轴③
- **THEN** 不再单独出现“反弹目标”“回撤目标位”“通道参考”和“近端看”段落；通道边界作为梯子中的一档，或写成梯子下的一行备注

### Requirement: 轴② 已排除情景折叠为一行

轴② 当前进行浪结构表 MUST 只列出没有违规的情景。存在违规的情景 MUST 合并到表格下方一行，写成“已排除：<情景名>（<最重一条违规>）”。进行腿细化里的书页出处列表 MUST NOT 出现在 md 中。

#### Scenario: 下跌推动浪③ 违规

- **WHEN** 情景“下跌推动·浪③ 进行中”违规 1 条（浪② 越过浪① 起点 78063.3）
- **THEN** 结构表不再有这一行
- **AND** 表格下方出现“已排除：下跌推动·浪③（浪② 越过浪① 起点 78063.3）”

### Requirement: 轴① 备选同点位合并

轴① 备选表里，框架和各腿点位完全相同、只是浪型不同的若干行 MUST 合并为一行，浪型栏用“ / ”列出这些浪型，排名取其中最高的一个。主选 MUST 只呈现各腿端点和完成度，子浪验证证据 MUST NOT 出现在 md 中。

#### Scenario: 四种调整形态共用 a/b/c 点位

- **WHEN** 单锯齿、平台形、规则平台形、双重横向整理四个备选的框架都是 A，且 a/b/c 都是 78878.01→76663.9→78063.3→75736.38
- **THEN** 备选表中只有一行，浪型栏写“单锯齿 / 平台形 / 规则平台形 / 双重横向整理”

### Requirement: 调试信息只进 JSON

“规则树与打分”代码块、进行中结构代码块、子浪验证证据、书页出处、内部模式 id（如 `corrective-no-triangle`、`impulse-strict`）、数值打分字段（如 `越界0.000`、`指引0/0`）、开发备注（如“专章待补”）MUST NOT 出现在默认 md 中。这些信息 MUST 能在 `_tree.json` 中查到；JSON 中原本没有的，MUST 新增字段承载。

传入 `--verbose` 时，md MUST 按改动前的完整版式输出（本变更新增的价位梯子与折叠规则仍然生效）。

#### Scenario: 默认 md 无调试块

- **WHEN** 不带 `--verbose` 运行
- **THEN** md 中不含“规则树与打分”标题、`corrective-no-triangle`、`impulse-strict`、`越界0.`、“专章待补”等字样

#### Scenario: verbose 恢复完整版式

- **WHEN** 带 `--verbose` 运行
- **THEN** md 中包含“规则树与打分”、子浪验证证据和大级别背景全文

### Requirement: 免责声明与扎针说明各出现一次

md MUST 只有一条免责声明，位于简报之后。同一扎针的说明在大级别背景和顶层读法里 MUST 只完整出现一次，另一处最多写“见上”。

#### Scenario: 单一免责声明

- **WHEN** 报告渲染完成
- **THEN** “不构成买卖建议”或“非投资建议”在 md 中只出现一次

### Requirement: 简报目标全部到位时顺延下一档

简报第 4 条中，反弹目标位如果全部“已到”，MUST 改为给出价位梯子里现价上方最近的一到两档，并注明情景。上阻力/突破位已被站上时，MUST 同样顺延到现价上方的下一档阻力。简报中的续行浪名 MUST 与轴③ 一致。

#### Scenario: 三个 X 目标都已到

- **WHEN** X 目标 76364.71 / 76936.48 / 77677.91 都已到，现价 78462
- **THEN** 简报第 4 条不再列出这三个价位，改为给出现价上方的 78878.01（X 上限；窗口最高）及其下一档

### Requirement: X 浪按整段 W 度量时续行浪为 Y

反弹身份为 X 连接浪、且因越过末腿起点而改按整段 W 度量时，之后的续行浪 MUST 称为 Y 浪（书 §7：X 之后的 Y 对比 W）。只有按“上一子浪”度量的 XX 连接浪读法，续行浪才 MUST 称为 Z 浪。简报、轴③ 与 `_tree.json` 中的 `aftermath` MUST 使用同一个浪名。

#### Scenario: 反弹越过末腿起点

- **WHEN** 反弹已越过末腿起点 77886.86，X 改按整段 78878.01→75736.38 度量
- **THEN** 轴③ 写“走完之后是 Y 浪下跌”，简报写“警惕 Y 浪”，JSON 中 `xx.aftermath` 以“Y 浪”开头

#### Scenario: 未越过末腿起点

- **WHEN** 反弹未越过末腿起点，按上一子浪度量
- **THEN** 续行浪写作 Z 浪

### Requirement: 进行中腿默认只出大白话

未传入 `--verbose` 时，轴② 的“进行腿细化”与“上表内部细化导读” MUST 替换为一节“这段回调（或反弹）走完了吗（X → Y）”，内容只包括：

- 现在反弹（回落）到哪、收回了这段回调的百分之几；
- 编号列出的几种可能（已走完 / 横着走 / 还要新低，按引擎实际存在的读法取舍）；
- “看这几条线”：每条价位对应支持哪种可能；
- 各情景的常见时间窗（若有）。

身份对照表、§3.3 级别段、形态内部价链、读法一 / 二 / 三全文、两条 70% 线辨析、分级失效线和内部导读 MUST 只在 `--verbose` 下输出。

轴③ 的“进行中腿的条件目标” MUST 在默认 md 中压成一两句：跌破（升破）结构线后先看哪一档、再看哪一档（共振的标“多种读法共振”），以及最早到期的时间上限及其形态。逐形态的倍数、指引线、规则失效价 MUST 只在 `--verbose` 下输出。大白话引用的 70% 线与跌破后目标 MUST 作为档位列入轴③ 价位梯子。

#### Scenario: 日线回调未走完

- **WHEN** 摆动段 57800.19→87395.67，回调到 75736.38 后反弹最高 81196.01，未传 `--verbose`
- **THEN** 轴② 出现“## 这段回调走完了吗（87395.67 → 75736.38）”，写明收回 47%、三种可能，以及 87395.67 / 83897.88 / 75736.38 三条线
- **AND** md 不含“## 进行腿细化”“**身份对照**”“**读法一”“**两条 70% 线”“## 上表内部细化导读”“**(z) 浪两条路**”
- **AND** 价位梯子含 83897.88“回调 70% 线”一档
