# Proposal

## Why

`analyze-wave-tree.js` 产出的 `_tree.md` 已经过长：以 BTC-USD 1h、2026-10-31 起的窗口为例，全文 243 行、约 21K 字，其中真正给人看的简报只有 23 行。读者实际会读的是简报和轴②、轴③，而这两部分被以下内容稀释：同一组点位重复出现（例如 0.382/0.5/0.618 回撤位出现 4 次，失效位 75736.38 出现 46 次）；与 1h 窗口无关的月线背景和“自价格 0”顶层读法，约 60 行；规则树、子浪证据、书页出处、工程术语等调试信息，约 50 行。此外，轴③ X 浪改按整段 W 度量后，续行浪仍写作“Z 浪”，与简报里的“Y 浪”矛盾。

## What Changes

- **轴③ 改为价位梯子**：反弹目标、回撤位、阻力/支撑、失效位按价格从高到低排成一张表，并标注每档的含义和所属情景。现价、窗口高点 S 一并列入；“X 已回撤 W 的 N%”以及 X 浪幅度上限对应的价位也要列出。时间窗和“走完之后”只写一次。原来的“反弹目标”“近端看”“回撤目标位”“通道参考”合并进这张梯子。
- **轴② 精简**：存在违规的情景（❌）不再单独占一行，改为表格下方一行“已排除：…”。重复出现的说明注释和“约束出处”书页列表移出 md。进行腿细化默认改为一节大白话“这段回调走完了吗”（几种可能 + 看哪几条线 + 时间窗），身份对照、读法一/二/三、§3.3 级别段和内部导读移到 `--verbose`；轴③“进行中腿的条件目标”压成一两句。
- **轴① 压缩**：主选只保留五条腿和完成度。备选中各腿点位完全相同的几行（如单锯齿 / 平台形 / 规则平台形 / 联合形）合并为一行。
- **大级别背景改为一段大白话**：默认 md（任何主周期）把“大级别背景”和“顶层读法”合并为一段不含术语的话（前段大涨/大跌途中最深回调多少、这轮走了多少、据此判断前段是否已走完）；父级表下的顶层佐证移到 `--verbose`；全文仍写入 `_tree.json`。
- **调试信息只进 JSON**：规则树与打分、子浪验证证据、书页出处、内部 id 和术语（`corrective-no-triangle`、`impulse-strict`、`越界0.000` 等）不再出现在 md 中。
- **新增 `--verbose`**：开启后按改动前的完整版式输出，便于排查问题。
- **去除重复**：免责声明全报告只保留一处。扎针说明在背景与顶层读法之间只出现一次。
- **简报**：如果反弹目标全部“已到”，第 4 条改为给出上方下一档（取自价位梯子），不再列出三个“已到”。上阻力已被站上时，同样顺延到下一档。
- **修正 Y/Z 浪名**：X 浪改按整段 W 度量后，续行浪名为 Y（X 之后是 Y）；只有按上一子浪度量的 XX 读法才接 Z。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `wave-count-tree`：Markdown 报告新增“价位梯子”“调试信息只进 JSON”“同点位备选合并”“已排除情景折叠”“简报顺延下一档”“`--verbose` 完整版式”等呈现要求；修正 X 浪按整段度量后的续行浪名。
- `higher-degree-background`：默认 md 中大级别背景与顶层读法合并为一段大白话，全文只在 `--verbose` 下输出（JSON 不变）。

## Impact

- 代码：`analyze-wave-tree.js` 的渲染函数（`renderMarkdownReport`、`renderBrief`、轴②/③ 相关渲染，以及 `renderHigherDegree`、`renderTopLevelReadings` 的调用处），`bounceHypotheses` 中 `xx.aftermath` 一处字符串，`main()` 新增 `--verbose` 解析。
- 数据：`_tree.json` 既有字段保持不变（`bounceHyp` 不进 JSON，`aftermath` 修正只影响 md）。被移出 md 的内容都已在 JSON 中，无需新增字段。
- 下游：`advise.js` / `advisor/` 不读 `_tree.md` 和 `_tree.json`，不受影响。
- 测试：断言旧 md 版式的测试需要更新。（golden 测试中的 `bounceHyp.xx.aftermath = 'Y 浪下跌'` 模拟的是父级联合形路径，不是这个 bug 的补丁，保留。）
