# Spec Delta

## ADDED Requirements

### Requirement: 当前进行浪排名软分须含上冲段性格契合度

当前进行浪竞争结构（轴②表）的排名 SHALL 先按硬约束违规数（tier1）升序，再按软分降序。软分 MUST 由两部分相加：
- **已验证腿数**：已走腿经引擎按其假设角色验证为通过的条数；
- **性格契合度**：上冲 / 回落段（已确认极值 → 摆动极值）的内部性格与该情景对第一腿的要求是否相符——要求第一腿为五浪（如"新推动·浪②进行中"的浪①）而性格为五浪时记 1，要求第一腿为三波（如"连接浪 / B·中继"读法按三波反弹定主次）而性格为三波时记 1，否则记 0。

已验证腿数 MUST NOT 覆盖性格契合度。每条情景 SHALL 在序列化中给出性格契合度与软分来源说明。

#### Scenario: 上冲段五浪时转势排在中继之前
- **WHEN** 两条情景硬约束违规数相同、已验证腿数相同，上冲段内部性格为五浪
- **THEN** "新推动·浪②进行中（转势）"排在"X 连接浪 / B·中继"之前

#### Scenario: 上冲段三波时中继排在转势之前
- **WHEN** 两条情景硬约束违规数相同、已验证腿数相同，上冲段内部性格为三波
- **THEN** "X 连接浪 / B·中继"排在"新推动·浪②进行中（转势）"之前

#### Scenario: 软分来源可追溯
- **WHEN** 序列化当前进行浪竞争结构
- **THEN** 每条情景带性格契合度数值与软分来源说明（已验证腿数、性格是否契合）

### Requirement: 楔形长度递减为指引
引导楔形与（收缩）终结楔形 MUST 以"1–3 与 2–4 边界向未来收敛"作为硬规则（书§2.3：楔形适用收缩艾略特通道）。"3 浪短于 1 浪、5 浪短于 3 浪"在书第 1~7 章无原文（楔形专章缺失），SHALL 只作指引：不满足时不计入硬约束违规，只是不命中该指引。扩散终结楔形 MUST NOT 套用这条指引。

#### Scenario: 边界收敛但 3 浪长于 1 浪
- **WHEN** 下行引导楔形 87395.67→82563→87220→80393.56→84352→79800（1 浪 4832.67、3 浪 6826.44，边界收敛）
- **THEN** 硬规则全部通过，"3 浪短于 1 浪"指引不命中；该段可作单锯齿的 (a)

#### Scenario: 边界不收敛仍淘汰
- **WHEN** 楔形的 1–3 与 2–4 边界向未来张开
- **THEN** 引导楔形 / 收缩终结楔形计 1 条硬约束违规，与长度是否递减无关

### Requirement: 细枢轴不漏摆动
`detectPivots` 产出的细枢轴 MUST 高低交替，且相邻两个枢轴之间（不含两端 K 线）MUST NOT 有比两端更极端的价格。为此：
- 同一根 K 线既是局部高点又是局部低点（外包线）时 SHALL 两侧都出枢轴，日内先后按阴线先高后低、阳线先低后高、平盘离开盘近的一端先到估计，并标 `outsideBar`；
- 相邻同型枢轴 SHALL 先补上其间最极端的反向 K 线，再按"留更极端者（同价留后者）"合并；被去掉的反向摆动越过它所落入那一段的另一端时 MUST 保留三点；
- 方向颠倒的段（高点低于前一个低点，或低点高于前一个高点）SHALL 成对去掉；
- 每个中间枢轴 SHALL 归位到它与前后两个枢轴之间同向最极端的 K 线。

#### Scenario: 外包线的另一侧不再丢失
- **WHEN** BTCUSDT 日线 2026-04-29 高 77904.93、低 74937.52，同为局部高点与局部低点
- **THEN** 两个价位都是枢轴，74937.52 不再随同型合并丢失

#### Scenario: 方向颠倒段去掉
- **WHEN** 逐级下跌中出现低点 94012.45（11-14）之后紧跟高点 93160（11-20）
- **THEN** 这对枢轴去掉，前后枢轴直接相连

#### Scenario: 小反弹照旧合并
- **WHEN** 两个相邻低点之间的反弹没越过前一个高点
- **THEN** 合并为一个低点，不新增枢轴

## MODIFIED Requirements

### Requirement: Markdown 报告按主题轴单一权威呈现

Markdown 报告 MUST 按三条主题轴组织，每个主题 MUST 只有一处权威呈现，其余位置至多以一句导读指向权威处、不得重复列出其明细：

- **轴①「大跌走完了什么形态」**：整段历史下跌的形态判定（数法排名）为权威；"整段在更大结构里的角色"（父级候选）MAY 作为其子块出现，但 MUST NOT 重新罗列大跌形态本身。
- **轴②「当前反弹是什么结构」**：当前进行浪竞争结构表（T1-T4 一类的具体子计数枚举）为权威；当前段内部细化、反弹身份研判（连接浪/B/推动）等 MUST 收敛为对该权威表的导读或并入该节，MUST NOT 用另一套字母系统对同一段反弹独立重述一遍。表中 ⏳ 进行中腿（如摆动极值之后的回撤）的内部结构细化——本回撤在各存活情景中的身份与约束、级别、内部形态、整体读法——MUST 并入本节，内部浪名 MUST 使用低一级记号。
- **轴③「接下来往哪、何时」**：反弹目标价、失效点、斐波时间窗 MUST 集中于此；⏳ 进行中腿的目标位（回撤位、内部末浪目标、平台形末浪目标）亦归于此；时间窗内容 MUST 在整份报告中只出现一次。

大白话版 MUST 降级为纯结论 + 指路（TL;DR），MUST NOT 整体复述上述三轴的明细。

本要求仅约束呈现层；引擎派生、评分与 `_tree.json` 序列化的既有字段 MUST 保持不变（其它要求明文新增的字段除外）。

#### Scenario: 当前反弹只用一套权威标签

- **WHEN** 报告渲染存在当前反弹段（`spanLast → 摆动极值 → now`）的行情
- **THEN** 该反弹的具体子计数只在轴②权威表呈现一次
- **AND** 其它节 MUST NOT 用 `a-b-c`、`XX·B·三浪`、`锯齿` 等另一套标签对同一段反弹独立重述明细，至多出现一句指向轴②的导读

#### Scenario: 进行中腿的结构细化归轴②

- **WHEN** 报告存在摆动极值之后的进行中回撤，且生成了回撤研判
- **THEN** 回撤的身份对照、级别、内部形态与整体读法出现在轴②内、紧随权威表
- **AND** 轴③只出现该回撤的目标位，并以导读指向轴②的身份对照

#### Scenario: 转折时间窗全报告仅一次

- **WHEN** 报告包含斐波时间窗内容
- **THEN** 时间窗小节在整份报告中 MUST 恰好出现一次（归属轴③）
- **AND** 旧的"现状研判③"与大白话"可能的转折时间窗"MUST NOT 并存

#### Scenario: 目标价与失效点集中呈现

- **WHEN** 报告给出反弹目标价与失效点
- **THEN** 明细 MUST 归集于轴③一处
- **AND** 其它节引用同一数字时 MUST 指向轴③、MUST NOT 各自重列一套目标阶梯

#### Scenario: 父级=联合调整时统一层级记法

- **WHEN** 父级候选主选为「联合调整（w-x-y）」且报告展示当前段内部细化
- **THEN** 该内部细化 MUST 以 `w/x/y` 记法呈现（而非 `a-b-c`），并 MUST 显式标注"整段反弹"外层单位与"反弹内部形态"内层单位的级别归属
- **AND** 读者 MUST 能据此区分"外层 w（可为任意调整形态、非 5 浪）"与"内层锯齿的 A（应为 5 浪）"

#### Scenario: 序列化数据零改动

- **WHEN** 对同一输入分别在呈现层改动前后运行
- **THEN** `serialize*` 产出的 `_tree.json` 既有字段 MUST 完全一致；仅其它要求明文新增的字段可以出现

#### Scenario: 大白话版为 TL;DR

- **WHEN** 报告渲染大白话版
- **THEN** 其内容 MUST 限于一句大局结论、一句当前处境、以及指向轴②/轴③的导读
- **AND** MUST NOT 包含"拆成几大段""现在走到哪了内部拆解""接下来可能到哪"等对三轴明细的第二遍复述

### Requirement: currentPullback 序列化扩展（回撤叙述子字段）
`inProgressTree.currentPullback` 的 JSON 序列化 SHALL 在保留现有字段的前提下，新增以下子字段，
且这些字段 MUST 与主计数树平级隔离（不改写主树，级别卫生）：
- `subDegree`: `{ tf, rankedPatterns[] }`——下钻所用子级别及其滤除违规后的竞争形态列表；
- `combinationReading`: `{ legs, xxRetracePct }`——联合形逐腿（W/X/Y/XX/Z）与 XX 对 Y 的回撤百分比；
- `structureLine`: 回撤真低点（续涨条件/拆段收尾点）；
- `zwaveTargets`: `{ breakPath[], trianglePath }`——Z 浪跌破路径完整目标阶梯与三角收缩路径；
- `narrative.axis2Roles[]`：本回撤在轴②各存活情景中的身份、书中约束、现状对照与下一腿投影；
- `narrative.retraceLevels[]`：对上冲段（已确认极值 → 摆动极值）的回撤位及其与内部末浪目标的共振标记；
- `narrative.completedReading`：读法三（进行中腿已在回撤真低点走完）的终点、否定线、70% 线、摆动极值、内部形态、轴②下一腿与投影、单锯齿首段 (a) 测算；不适用时为 null；
- `subDegree.rankedPatterns[].beyondEnds[]`：非末段终点之前段内更极端的细枢轴（失败第五浪 / 截断），无则为空数组（BTC 现例各段终点均为跨度极值，为空）；`points[]` 新增 `index`；
- `narrative.extensionReading`：末段延伸读法的触发价、状态与各形态的常见目标、指引线、规则失效价、时间上限及共振标记；不适用时为 null。
当某项无法计算（如回撤未拆出联合形、未下钻、轴②无存活情景）时，对应字段 SHALL 为 null 或空数组，MUST NOT 报错。

#### Scenario: 联合形回撤输出全部子字段
- **WHEN** currentPullback 在子级别拆为联合形且 Z 浪可投影
- **THEN** JSON 的 currentPullback 含 subDegree / combinationReading / structureLine / zwaveTargets 四子字段，数值均由本次 K 线计算

#### Scenario: 无联合形读法时子字段降级为 null
- **WHEN** currentPullback 未拆出联合形（如枢轴仍不足、下钻后也不成形）
- **THEN** combinationReading 与 zwaveTargets 为 null，structureLine 仍给出真低点，序列化不报错

#### Scenario: 轴②无存活情景时身份为空
- **WHEN** 轴②所有情景均有硬约束违规
- **THEN** `narrative.axis2Roles` 为空数组，其余子字段照常，序列化不报错

#### Scenario: 子字段不影响主树序列化
- **WHEN** 序列化整棵树
- **THEN** 主计数树（tree）输出与新增子字段前完全一致，新增字段仅出现在 inProgressTree.currentPullback 下
