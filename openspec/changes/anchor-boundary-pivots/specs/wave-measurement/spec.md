# wave-measurement

## ADDED Requirements

### Requirement: 数浪范围锚定区间首尾
枢轴序列在用于浪型扫描前 SHALL 被锚定到分析区间的首尾：起始枢轴取「首根K线 → 第一个检测枢轴」前导区间的极值（类型与第一个检测枢轴相反），终止枢轴取「最后一个检测枢轴 → 末根K线」尾部区间使数浪抵达当前。锚定后枢轴类型 MUST 保持严格交替、无重复索引。

#### Scenario: 起点极值被纳入枢轴
- **WHEN** 分析区间首根K线的高点是全局最高、但落在被 `detectPivots` 跳过或被 ATR 过滤掉的前导区间内，且第一个检测枢轴是低点
- **THEN** 枢轴序列前置一个高点枢轴，价格为前导区间最高价、位置在第一个检测枢轴之前（例：BTC-USD 1d 前置 `H126296.00 @ 2025-10-06`）

#### Scenario: 终点沿趋势延续则延伸末枢轴
- **WHEN** 最后一个检测枢轴是低点，且其后到末根K线之间出现了更低的低点
- **THEN** 该末枢轴被替换/延伸为尾部区间的更低低点（不新增同类型枢轴）

#### Scenario: 终点反转则追加当前摆动极值
- **WHEN** 最后一个检测枢轴是低点，且其后价格反弹（未创更低低点）
- **THEN** 枢轴序列追加一个高点枢轴，价格为尾部区间最高价，使数浪抵达当前

#### Scenario: 极值恰在边界枢轴上时不重复
- **WHEN** 前导/尾部区间的极值恰好就是第一个/最后一个检测枢轴本身
- **THEN** 不前置/追加重复枢轴，序列保持不变
