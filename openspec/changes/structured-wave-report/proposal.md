# 提案：结构化波浪分析报告（7 节自然语言）+ 修平票口径

## Why

现有报告(数法排名/结论/现状研判/大白话/技术细节)是多轮迭代堆出来的，信息全但**不是一份
面向阅读的完整分析**。用户要一份**固定 7 节结构、以自然语言叙述、可直接读**的波浪分析报告，
并对分析深度提出硬要求：

- 若某段判为 W-X-Y，报告 MUST 逐一说明 W/X/Y 的起止时间价格、各自内部结构、以及**为什么是
  W-X-Y 而不是单锯齿/五浪推动/平台**——不能只写"看作 W-X-Y"。
- 最后一个转折点之后的行情 MUST 同台评估多方案(XX 反弹 / 更大级别 B / 新推动1浪 / 新推动3浪 /
  其它合规方案)，且**不得因涨幅大就判 3 浪**——判 3 浪前须逐条结构验证。
- MUST 说明**反弹在修正哪一段**(XX 对应上一子浪 Y；B 对应整段完整结构)，两方案各自的修正对象
  和目标区间都要写清。

引擎内部其实已算出大部分素材(W/X/Y 拆解、内部结构、比例、反弹修正对象+目标、多方案排名、
违规原因)，缺的是**一套新输出格式 + 几处新计算 + 一处评分口径修正**。

## What Changes

对 `analyze-wave-tree.js`（其余文件零改动）：

1. **新增结构化报告输出（不替换现有报告，探索 A=a）**：新增一种 7 节 Markdown 报告
   （1 分析范围 / 2 关键转折点 / 3 已完成浪型 / 4 当前主方案 / 5 备选方案 / 6 方案排序 /
   7 最终话术），经 CLI 开关（如 `--report structured` 或独立输出文件）产出；现有报告保留。

2. **不用概率百分比（探索 B）**：第 6 节"排序表"不给伪概率，用**高/中/低**三档（由违规数 +
   越界程度客观分档）+ 支持依据/不利因素/确认条件。

3. **wave-3 验证清单去掉"动能/速度扩张"（探索 C）**：坚持既有「无动量/书外指标」原则。判"新推动
   3 浪"前只做**书内结构验证**：是否有可识别的第1浪、符合规则的第2浪、第2浪未跌破第1浪起点、
   当前是否突破第1浪高点、内部是否形成五浪推动、是否突破前一轮下跌的关键结构高点。**不引入
   RSI/动量**；"动能扩张"以"3浪须最强/幅度扩张"等结构性书内判据替代或省略。

4. **修平票口径，让主方案与真实拟合对齐（探索 D=b）**：当前文法违规在 tier2(越界)记 0，导致
   "结构不对的单锯齿"能压过"只差 0.5% 比例的 W-X-Y"。改为**文法违规也带一个越界权重**，使
   "差一丝比例"的候选不再被"结构性格不对"的候选平票压下——排名主选会更贴合真实拟合（当前数据
   下很可能自然变为 W-X-Y）。

5. **新增几处计算**：关键转折点的"暂定浪型位置"映射；W/X/Y 的**时间比例**；"为何不是
   单锯齿/五浪/平台"的对比叙述（复用刚加的逐候选违规原因）。

## Impact

- 改动文件：`analyze-wave-tree.js`（新报告渲染、CLI 开关、时间比例/浪位映射、平票口径）。
- 涉及能力：`wave-count-tree`（新结构化报告输出 + 转折点浪位/时间比例），`wave-fit-scoring`
  （文法违规越界权重）。
- 不改：数据源、既有报告、`analyze-kline-wave.js`、`analyze-wave-manual.js`。
- 兼容：平票口径改动会重排"违规×1 平票"的候选（金标准前后对照兜底）。

## 非目标

- **不引入书外指标**（动量/RSI）——wave-3 只做书内结构验证。
- **不给统计概率**——只给高/中/低档 + 依据。
- **不替换现有报告**——新旧并存。
- 不改形态硬规则本身；平票口径只调"文法违规的越界权重"。
