## 2. 关键设计点

### 2.1 反弹修正对象（核心要求，已有）
`bounceHypotheses` 已算：XX 对"上一子浪"(如 Y=97964→57718，回撤 0.2–0.618)；B 对"整段"
(126296→57718，0.5/0.618/0.7)。§4/§7 直接叙述两方案各自修正哪段 + 目标区间。**不得只写
"可能是 XX 或 B"而不点明修正对象**——这条是硬要求，渲染层强制两方案都带修正对象。

### 2.2 wave-3 结构验证（去动能，探索 C）
判"新推动 3 浪"前，逐条书内结构验证（可算项）：
```
① 存在可识别的第1浪（上涨段能拆出干净五浪的第1子浪）
② 存在符合规则的第2浪（回撤 ≤100% 第1浪、未破第1浪起点）
③ 第2浪未跌破第1浪起点（硬）
④ 当前价突破第1浪高点（价格比较）
⑤ 内部形成五浪推动（legCharacter=driving 且干净）
⑥ 突破前一轮下跌的关键结构高点（价格比较）
```
全过才提升 3 浪概率档；**"动能/速度扩张"不做**（无动量原则）。"不得因涨幅大直接判 3 浪"由
"必须①–⑥逐条过"来落地。

### 2.3 高/中/低分档（探索 B + 6节 b）
不给百分比。按候选的 (违规数, 越界和, 未完成度) 客观分档：
```
高 = tier1==0（规则全过）或 tier1==1 且越界极小(<阈值) 且非在建
中 = tier1==1 一般 / 或在建但结构合规
低 = tier1≥2 或越界大 或 硬闸门濒临失效
```
阈值可迭代；档位是"相对强弱"，不冒充统计概率。

### 2.4 平票口径修正（探索 D=b）—— wave-fit-scoring
现状：文法违规计入 tier1(条数)，但 tier2(越界和) 记 0 → "结构不对的单锯齿(文法违规,越界0)"
在 tier2 上压过"差 0.5% 比例的 W-X-Y(越界0.005)"。
改：**给每条文法违规一个固定越界权重 `GRAMMAR_OVERSHOOT`（如 0.5），计入 tier2**。理由：
"腿的性格根本不对"是结构性硬伤，不应比"差 0.5% 的比例"更轻。加权后：
```
单锯齿：tier1=1, tier2=0.5(文法)      ← 变重
W-X-Y ：tier1=1, tier2=0.005(比例)    ← 更轻 → 升为主选
```
权重值需回归金标准标定（太大可能过度压制文法违规候选、太小无效）。这一步让报告"主方案"与
"真实最贴合的读法"对齐，不再钉在结构可疑的单锯齿上。

## 3. 影响面与风险

- 平票口径(2.4)是**引擎级排序**改动：所有"违规×1 平票"的地方会重排；金标准前后对照兜底，
  确认重排都来自"文法违规不再白占 tier2 便宜"。
- 新报告是**新增渲染 + CLI 开关**，不动既有报告与树结构。
- §7 话术是模板化拼接现成要素，非自由生成——保证数字与前几节一致、不臆造。
- wave-3 清单若数据不足（子枢轴太少拆不出第1浪）应如实标"无法验证"，不硬判。

## 4. 分步落地建议

1. 先做 2.4 平票口径（小、引擎级，先让排名主选正确）+ 金标准回归。
2. 再做新报告渲染（§1–§7），逐节接数据；§2 浪位映射、§3 时间比例、wave-3 清单为新计算。
3. §7 话术最后拼。CLI 开关最后接。
