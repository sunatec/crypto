# wave-fit-scoring

## MODIFIED Requirements

### Requirement: 文法违规须带越界权重，不得在 tier2 白占便宜
文法违规（子腿性格无法胜任所需角色）除计入 tier1 条数外，MUST 也带一个固定的越界权重计入
tier2（越界和）。此前文法违规在 tier2 记 0，导致"结构性格不对"的候选在越界维度上压过"仅差
一丝比例"的候选（如结构不对的单锯齿平票压过只差 0.5% 比例的 W-X-Y）。加权后，"腿的性格根本
不对"这类结构硬伤 SHALL NOT 被当作比"小比例越界"更轻，使同为违规×1 的候选按真实拟合排序。

#### Scenario: 文法违规不再压过小比例越界
- **WHEN** 候选甲仅有一条文法违规（如 a 腿该五浪却像三波），候选乙仅有一条小比例越界
  （如 y/w 比例差 0.5%），二者 tier1 同为 1
- **THEN** 文法违规计入 tier2 的权重使候选甲的 tier2 大于候选乙 → 候选乙（更贴合）排在前

#### Scenario: 无文法违规的候选不受影响
- **WHEN** 候选没有文法违规
- **THEN** 其 tier2 仅由规则越界构成，与本改动无关、排序不变
