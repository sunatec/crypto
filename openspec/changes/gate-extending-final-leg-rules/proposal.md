# 提案：延伸中的末腿——终点锚在真极值，且只查「可判定」规则

## Why

`model-unfinished-final-wave` 交付了逆势框架B（末浪进行中、极值只是拐点），但当前实现有两处遗留缺陷，在 BTC 1d 现价（反弹到 78301）这个真实样本上同时暴露：

**缺陷一：逆势反弹时，朴素框架B 抢占了逆势框架B，末腿终点被钉在反弹价上。**

`buildCountTree` 的框架B 分派（[analyze-wave-tree.js:1603](analyze-wave-tree.js:1603)）是：

```js
tree.frameworkB = (naiveB && naiveB.primary) ? naiveB : buildCounterTrendFrameworkB(...)
```

注释假设「now 落逆势极值 → 朴素B 首尾类型不匹配 → 返回空 → 走逆势B」。但该假设会漏：现价 78301 位于近端摆动高 81265 **之下**，被识别成一个"临时低点"，朴素B 照样拟合成功（`126296→80525→97964→78301`），抢在逆势B 前占位。后果是排名表里的框架B 候选（备选2 双锯齿、备选6 联合形）末腿写成 `y:97964→78301⏳`——**一条"下跌进行中"的腿，终点(78301) 却高于它自己内部已砸出的低点(57718) 两万点**。真极值 57718 被压进 y 腿内部藏掉了，读者看到的是"这波只跌到 78301"，与实际"砸到 57718 后反弹回来"相悖。

**缺陷二：延伸中的末腿仍被全套规则判违规，包括"幅度下界"这种延伸能翻转判决的规则。**

`model-unfinished-final-wave` 的设计注释（[analyze-wave-tree.js:217](analyze-wave-tree.js:217)）已写明这是暂缓项：

> 完整设计要求「进行中的末腿**只查可判定规则**」…本次先用整体性惩罚项（未完成度）作为主要公平机制：末腿仍按现有规则**全查**。

于是备选2 头上挂着 `❌违规×1：y浪价格须>90%w`。但 y 是**下跌延伸中**，延伸只会让 |y| 变大、`y/w` 单调逼近并越过 0.90——这条规则的判决**会被后续延伸翻转**（从违规变通过）。对一条还在长的腿套用幅度下界规则判违规，逻辑上不成立。

## What Changes

对 `analyze-wave-tree.js`（`analyze-kline-wave.js`、`analyze-wave-manual.js` 零改动）：

1. **末腿终点锚在真极值（方案A / 修缺陷一）**：框架B 的进行中末腿终点 MUST NOT 落在"逆势回撤点"（下跌腿终点高于其区间内已达低点、或上涨腿终点低于已达高点）。当 `now` 与顶层净方向逆行时，即便朴素框架B 能拟合出一条终结于 `now` 的末腿，也改用逆势框架B——末腿锚定顺势极值（如 57718），当前反弹（→78301）作为末浪内部回撤，标「⏳延伸中」并向极值另一侧投影。

2. **末腿可判定性闸门（修缺陷二）**：对 `finalWaveInProgress` 的进行中末腿，按**单调性判据**决定每条规则查还是暂缓——「已违反、且末腿的合法延伸只会加剧」→ 判违规（可判定）；「尚未违反、但延伸可能触发或解除」→ 暂缓、不计入 tier1 违规。上界（y<5倍w）与下界（y>90%w）统一按此处理。被暂缓的规则**标注为「⏳待末腿走完再判」**、透明可见。未完成度惩罚（incompleteness）**保留**，与闸门并存、各司其职。

## Impact

- 改动文件：`analyze-wave-tree.js`（框架B 分派判据、末腿终点约束、进行中末腿的规则闸门、排名表违规呈现）。
- 涉及能力：`wave-count-tree`（框架B 进行中末腿的终点语义、规则可判定性闸门、违规呈现）。
- 产出变化：所有 framing=B 进行中候选的末腿 from/to、状态标签（进行中→延伸中）、tier1 违规数与违规明细；直接改变 `_tree.md` 数法排名表、`_tree.json` rankedCounts、`_structured.md`。当前样本影响备选2（双锯齿）、备选6（联合形）。
- 不改：数据源、CLI、框架A 宏观骨架、`rank-competing-wave-counts` 的搜索/beam/去重、未完成度惩罚的存在性。

## 非目标

- **不改形态集**、不放开 `maxDepth`、不引入书外指标。
- **不做规则闭包的全量单调性标注**——只对"末腿幅度/比例/等长/回撤比"这一族依赖终点的规则接入闸门；结构类型、方向、子浪数等与终点无关的规则维持照查。
- **不重构未完成度惩罚**——它与闸门是两件事，保留。
