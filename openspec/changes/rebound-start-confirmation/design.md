# Design

## Context

`enrichCurrentPullback` 只处理“确认低点 → 上冲 → 回撤下行”（`structUp === true`）。回撤段 `swingExtreme → 真低点` 会被下钻到更细周期拆形态，但下钻窗口止于主周期最后一个枢轴的 K 线开盘时间，拿不到低点之后的日内反弹。反弹确认线需要的恰恰是低点前后的小周期细节，所以单独取一次数。

## Goals / Non-Goals

**Goals**
- 跌出新低时，所有确认线和门槛都按新低自动重算。
- 默认报告只给价位、说明和现状；推算过程进 `--verbose`。
- 纯函数部分离线可测。

**Non-Goals**
- 不改主计数树、轴② 排名、轴③ 既有目标。
- 不处理 `structUp === false`（下跌后的反抽），留待以后镜像。
- 不对反弹做完整的数浪，只按一次最深回调定 ①/②。

## Decisions

### D1 取数周期

- 主周期为 1h 或 5m：直接用主周期的 K 线与枢轴，不另取数。
- 主周期更大：取 `swingExtreme.timestamp → endTs` 的 1h K 线；超过 3000 根时改用 4h。
- 用的是 1h 时，再取 `末段起点 → endTs` 的 15m K 线，找最早信号那一行；取不到或找不到就省掉这一行。
- 取数失败、K 线不足 2 根：`reboundConfirmation` 为 null，不输出。

### D2 高点、低点与下跌段的枢轴

- 高点：从 `swingExtreme.timestamp` 起，K 线最高价的最大值（应与摆动极值一致）。
- 低点：高点之后 K 线最低价的最小值。按 K 线取，不只看枢轴：边界锚定只会补一个与末确认枢轴反向的极值，最后几根 K 线再创新低时，枢轴里看不到。
- 下跌段枢轴：取细周期枢轴中时间落在 `[高点, 低点)` 之间的那些，前面补上高点，末尾补上低点，构成 `D`。

### D3 反弹确认线（从近到远）

| key | 价位 | 说明 |
|---|---|---|
| `finer` | 15m 上，末段起点之后、低点之前的最后一个高点枢轴（须低于末段起点、高于低点） | 最后一小段下跌里最后一次小反弹被越过：最早的信号 |
| `finalLeg` | `D` 中低点之前的最后一个高点枢轴 | 最后一小段下跌结束，小级别反弹开始 |
| `degree` | 低点 + `maxInternalRetrace(D, false).depth` | 反弹超过下跌途中任何一次反弹：这一级下跌结束（书§3.3 镜像） |
| `origin` | 高点 | 整段回调结束 |

价位相同或不在 (低点, 高点] 区间内的行去掉；按价位升序排列。每行给出 `crossed`：低点之后任一根 K 线最高价 ≥ 该价位即为已越过，并记首次越过的时间。

### D4 推动浪门槛

在低点之后的 K 线上分段：维护“当前最高价”，K 线最高价超过它就开始新的一段，同时记录每一段里（当前最高价那根 K 线之后）的最低价。最深的一段回调给出 ① 高点 `h1` 与 ② 低点 `l2`。没有任何回调（一直创新高，或低点就是最后一根 K 线）时，门槛为 null。

为什么取最深而不是第一次：第一次回调往往只是 ① 内部的小波动（例如 78718→78001.77），取最深的一次与“② 是 ① 之后像样的回调”一致，也和用户手工读出的 81196.01 / 79952 吻合。

状态：
- `pending`：`h1` 之后的 K 线最高价没有超过 `h1`。文案为“守住 l2 且冲破 h1 → 可能在走五浪”，并提示“没冲破 h1 就跌破 l2 → 反弹更像三波，可能变大”。`l2` 落在最后一根 K 线上时标为暂定。
- `third`：`h1` 已被超过。文案为“已冲破 h1，可能在走第 3 浪；之后回调不得跌回 h1 下方”。
- `overlap`：`h1` 被超过之后，又有 K 线最低价跌到 `h1` 下方（但仍高于 `l2`，否则会成为新的最深回调）。文案为“冲破后又跌回 h1 下方：更像三波（A-B-C）”。

浪③ 目标：`l2 + m × (h1 − 低点)`，m = 1、1.618；`pending` 与 `third` 时进价位梯子。

### D5 与已有读法的对应

“这段回调走完了吗”中已有“已走完 / 横着走 / 还要新低”三种可能。五浪反弹支持“已走完”（新一轮上涨开始），三波反弹支持“横着走”。对应的读法存在时才点名，否则只写“反弹力度大 / 只是中途反抽”。

### D6 渲染

- 默认 md：在“这段回调走完了吗”节末（“身份对照……见 `--verbose`”之前）加 `### 止跌后反弹到哪算开始`，内容为一张三列表（反弹到 / 说明什么 / 现状）加门槛的两三行。
- `--verbose`：在回撤叙述里加同名小节，列出每条线的推算（价位 = 何处来），门槛的规则说明，以及 0.236 回撤位作为参考档（不进表）。
- 简报第 4 条：加“反弹确认：站上 X（说明）”，X 是最近一条未越过的线；全部越过时不加。
- 价位梯子：未越过的确认线和浪③ 目标进梯子，标签用大白话。

## Risks / Trade-offs

- 1h 分段对很小的反弹会给出很近的门槛（例如 76416.24 / 75360.81）。这是规则的直接结果，不额外过滤，用户可以对照图表判断。
- 多一次网络取数会拖慢运行。1h 已有缓存，15m 窗口很短。
- `maxInternalRetrace` 用的是枢轴，枢轴检测参数一变，升级线也会跟着变。这与 §3.3 的既有用法保持一致。
