# 设计：顶层末浪未走完的表达（修框架B逆势失效 + 软化框架A完成宣称）

> 本设计来自一次 explore 会话。前置：`rank-competing-wave-counts`（已交付框架A/B 与排名表）。
> 硬约束：仅改 `analyze-wave-tree.js`。

## 1. 缺陷定位（框架B 只覆盖了"读法2"的一半）

```
框架B 区间 = [全局极值 → now]，decompose 要求形态首尾类型与方向一致：
  now = 顺势新极值(下跌→新低 L)   → 终点 L，下行形态可终结 → 框架B 有候选 ✓
  now = 逆势反弹高点(下跌→ H)     → 终点 H，下行形态全被否 → 框架B 空 ✗  ← 缺陷
```

"读法2"（当前是更高级别未完成浪的子腿、极值只是中继）恰恰在"当前正处逆势反弹"时最该出现，
而这正是框架B 失效的那一半。于是框架A 的"完成@全局极值"成了唯一读法，过度宣称完成。

实证（BTC 1d）：现价反弹到 79500 时，框架B 区间 `H126296 → H79500(prov)`，净向下但止于 H，
全部下行形态因首尾类型不匹配被否，框架B primary=null。

## 2. 根因

`decompose(segFine, ...)` 里：
```
if (start.type !== seq[0] || end.type !== seq[seq.length - 1]) continue; // 首尾类型闸门
```
框架B 把 `end` 钉死为 `now`。当 `now` 是逆势极值时，`end.type` 与任何顺势形态的终结类型都不符 →
所有候选被跳过 → 无候选 → 叶子。**问题不在这条闸门（它对"完成形态"是对的），而在框架B 假设
"末浪终结在 now"**——当末浪还在逆势回撤时，这个假设不成立。

## 3. 方案（探索定：② 为主 + ① 顺带）

### 3.1 ② 框架B 终点改为"末浪进行中"（核心）

当 `now` 处于逆势极值时：
```
不把顶层结构终结在 now，而是：
  · 顶层宏观骨架仍用「到最后一个顺势极值」的点（如 126296/84400/97964/57718）——与框架A 同骨架
  · 但把「最后一个宏观浪」标为「进行中」：其终点是投影的未来极值（跌破 57718 的新低），
    当前的逆势走势（57718→79500 反弹）= 这条末浪内部的回撤（尚未走完）
  · 该读法作为框架B 的候选进入排名池，与框架A（同骨架但「末浪已完成」）并列竞争
```

关键区别一句话：**同一组宏观点，框架A 说"末浪已终结于极值"，框架B 说"末浪还在延伸、极值是其内部拐点"。**

实现要点（待 apply 阶段细化）：
- 判定 `now` 是否逆势极值：`now.type` 与顶层净方向的终结类型相反。
- 逆势时，框架B 复用「到顺势极值」的宏观点做顶层拟合，但对末浪调用类似 `annotateInProgress` 的逻辑
  标注进行中 + 投影终点（可复用 `computeLegExpectation`/回撤-延伸投影）。
- 末浪的"内部回撤"可复用现有 `inProgressStruct` 的 a/b/c 拆解（57718→now 那段已在做）。

### 3.2 ① 框架A 完成度措辞软化（顺带）

框架A 末浪终结于全局极值，但整段"是否完成"取决于极值是否被破：
```
"✅ 已完成（框架A：区间止于全局极值）"
  → "✅ 完成（待确认）：末浪终结于全局极值 X；若跌破/升破 X 则末浪延伸、见框架B 读法"
```
诚实反映"57718 未必是终点"，并与框架B 的竞争读法互相指引。

### 3.3 暂不做 ③

选项③（把"极值后的反弹"在"新结构 X/B（现 parentDegree）"与"未完成末浪内部回撤（框架B）"两种
身份间完全统一并列）牵涉 parentDegree 与框架B 的语义合并，范围更大。先交付 ②，若表达仍不足再评估。

## 4. 影响面与风险

- 改动集中在 `buildCountTree`（框架B 分支）、末浪进行中标注、`buildRankedCounts`/渲染的框架A/B 标签。
- 风险1（重复表达）：框架B 的"末浪进行中"读法与 `inProgressStruct`/`parentDegree` 的"反弹身份"
  可能在报告里两处讲同一段走势——需在渲染层理清分工（框架B=顶层数法之一；parentDegree=反弹在
  更大结构中的身份），避免读者困惑。
- 风险2（投影可信度）：末浪延伸的投影终点是推断，须明确标注"推断、非确定"，并给失效点。
- 风险3（回归）：软化框架A 措辞不得破坏既有金标准断言（金标准里有"顶层从126296起锚""进行中腿存在"
  等，须保持）。

## 5. 验证要点

- 逆势反弹现场（now=H，下跌净向）：框架B 不再空，产出"末浪进行中、投影新低"的竞争读法。
- 顺势新极值现场（now=L）：框架B 仍能产出"顺势延伸"读法（不回归）。
- 框架A 措辞含"待确认 + 失效点"，且金标准断言不破。
- 1d/1h 两周期端到端无 undefined/NaN、性能正常。
