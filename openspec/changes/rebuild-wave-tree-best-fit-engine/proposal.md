# 提案：以「递归拆解 + 最佳拟合」重写波浪计数引擎

## Why

现有 `analyze-wave-manual.js` 是一个**局部形态证伪器**：滑动固定窗口（4/6 点）逐个套形态手册、否定法闸门。它作为"某一段是不是合法推动浪/锯齿"的证伪器是合格的，但它**不是波浪计数器**，两处根本缺陷：

1. **"级别"是用过滤力度（lookback×倍数）伪造的，不是真正的包含关系。** 艾略特的 degree 定义是嵌套——N 级浪由 N−1 级浪构成且标注自洽。按振幅/间距过滤出的粗枢轴不保证就是细枢轴的浪级边界。之前的「缺陷3」（`97964→57717` 坍不成单一 Y 腿）只是这个病的症状。
2. **输出是一袋互相独立的局部候选，而非一棵覆盖全图、每根子浪都归位的计数树。** 用户真正要的是**一条从最大级别贯穿到当前所处浪型的计数链**，而滑窗架构在设计上就不产出这种东西。

此外，纯否定法只输出"谁活下来/谁被毙"，是二值的；用户的目标是"永远给出**最接近**的浪型"，这需要一层**拟合度/距离评分**，在没有任何形态完美通过时仍能给出最贴近的答案并量化差在哪。

## What Changes

**新建独立并行模块 `analyze-wave-tree.js`**，实现"以《波浪理论详解》全部可计算知识为准绳的最佳拟合浪型识别器"。**`analyze-kline-wave.js` 与 `analyze-wave-manual.js` 均零改动**，三者并存、可对照。

首要交付物 = **一条从最大级别贯穿到当前所处浪型的计数链**（主链 + 每层 top-K 备选 + 进行中浪的完成度与预期）。

核心变更：

1. **控制结构换血**：递归自顶向下拆解（文法 parser + 回溯 + beam），取代滑窗 bag-of-candidates。父浪约束子浪的可选假设集（1/3/5、a/c 只能用驱动类；2/4、b 只能用调整类）——这是"级别涌现"的机制。
2. **判据契约升级**：`test()` 从布尔 → 返回 `{pass, overshoot}`（相对阈值归一化的越界距离），以支撑分层字典序拟合分与 near-miss。
3. **分层字典序拟合分**：① 违规条数 → ② 越界距离和 → ③ 形态内指引未命中率 → ④ 跨级别指引（交替/父子斐波/通道，仅平局裁决）。有条件优雅降级：某节点无人全过规则时，回退最轻违规者并标注惩罚。
4. **级别涌现**：只吃一套细枢轴（lookback=1）+ 边界锚定，级别是拆解深度的涌现结果而非预设参数。
5. **进行中浪一等化**：每级别末浪标 `进行中(第X浪/共需Y浪)` + 预期（方向 + 斐波/通道目标区间，明确标注为推断）。
6. **书中知识分层落位**：硬规则=闸门；指引/斐波价格验证=打分；斐波时间共振/通道判别/交替/浪个性价格特征=平局裁决；斐波价格目标/通道完成=投影层（不评分，只出预期）；量能=仅注记；动量/背离=书外排除。

## 复用与丢弃边界（对旧文件采「采石场，非依赖」策略）

- **直接 `require` 复用（plumbing，理论中立）**：`fetchCandles`/`transformCandles`/聚合/`computeATR`/`detectPivots`/`anchorBoundaryExtremes`/`computeMeasures`/`rangeExtreme`/`buildChannel`/`fib*`/报告格式化。
- **搬内容 + 换契约**：各 `build*Manual` 的规则表达式移入新判据层（带 `overshoot`）；机械搬运，可疑处打 `// TODO 待对书校对`。
- **明确丢弃、不搬**：`legShape`/`legHasValidImpulse`/`legHasOverlap`/`legIsZigzagShaped`（被递归取代）、`scanCandidates`/`scanPositionalCandidates`/`scanAtDegree`/`DEGREE_CONFIGS`（滑窗 + 固定三档，退役）。

## Impact

- 新增：`analyze-wave-tree.js` 及其单元/结构/金标准回归测试。
- 不改：`analyze-kline-wave.js`、`analyze-wave-manual.js`、数据源、既有 CLI 与报告。
- CLI 沿用既有参数命名（`--product/--tf/--start/--end/--out/--report`）。

## 非目标

- **不新增形态**：形态集冻结为现有清单（推动浪 含引导/终结楔形、单/双/三锯齿、平台形 基础/规则/扩散/顺势、收缩三角形、双/三重横向整理）。扩散/边界三角形、更多联合组合子类留作后续增量。
- **不做逐条对书的规则全量校对**：先机械搬运让架构跑通，规则对错作为架构之上的独立迭代层（后审）。
- **不引入书外指标**：动量/背离/RSI 不参与判定；量能 v1 仅注记不评分。
