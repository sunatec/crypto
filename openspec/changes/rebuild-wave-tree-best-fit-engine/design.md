# 设计：递归拆解 + 最佳拟合波浪计数引擎

> 本设计经一次 grilling 设计会话逐节确认（18 项决策 Q1–Q18）。参考理论：《波浪理论详解》。
> 硬约束：新脚本独立成文件；`analyze-kline-wave.js`、`analyze-wave-manual.js` 零改动。

## 1. 定位（Q 定位修正）

以《波浪理论详解》**全部可计算知识**为准绳的最佳拟合浪型识别器：全假设竞争 + 硬规则闸门 + 软拟合评分 + near-miss 可解释。不是"规则+指引"两层，书中知识分工不同——有的是硬闸门，有的软打分，有的只驱动预期/目标，有的只作注记供人判。

## 2. 总体数据流

```
K线 → 细枢轴(lookback=1) + 边界锚定 → 递归拆解引擎(全假设竞争/回溯/beam)
    → 计数树(主链 + 每节点 top-3 备选) → console / Markdown / JSON
```

## 3. 判据契约变更（Q6 的直接后果）

`makeJudge` 的 `test()` 从**布尔** → 返回 `{ pass:boolean, overshoot:number }`：

- `overshoot` = 违反时"相对阈值归一化的越界距离"，通过则为 `0`。
  - 比率规则：超出 `[lo, hi]` 区间的量 ÷ 区间宽度（或阈值）。
  - 形态规则（如"3浪须超1浪终点"）：归一化价格距离 ÷ 参考浪幅。
- 这是实现 Q6/Q3 的前提——旧的纯布尔否定法**外壳不复用**，只搬规则**内容**。

## 4. 拟合分模型（Q6=a + Q3=b + Q11=b）：分层字典序

每个候选在某节点的排序键（全部升序，越小越优）：

| 层级 | 键 | 来源 |
|---|---|---|
| tier1 | 违反硬规则**条数** | pattern/ratio/time 规则 |
| tier2 | 违反规则的**越界距离之和** | 各规则 `overshoot` |
| tier3 | **形态内指引未命中率**（1 − 命中率） | 形态手册 guidelines |
| tier4 | **跨级别指引**（负，越多越优）：交替 / 父子斐波比例 / 通道贴合 / 浪个性价格特征 | 建树后计算 |

**优雅降级（Q3=b）**：字典序天然让 `tier1=0`（全过规则）排最前；当某节点**无人 `tier1=0`** 时，取 tier1 最小者作临时主选，并打 `违规 + 惩罚` 标记。near-miss 可解释 = 直接陈述"违反 N 条，最重的是 X 越界 Y%"。

## 5. 递归引擎（Q2 + Q8 + Q7 + Q12）

### 5.1 入口（Q8=a 全形态竞争）
对整段（起点锚 → 进行中末端），把每类顶层形态各拟合一次：

| 形态 | 需要段数 k |
|---|---|
| 推动浪 / 楔形 | 5 |
| 单锯齿 / 平台形 | 3 |
| 收缩三角形 / 联合形(w-x-y) | 5(a-b-c-d-e) / 3 |
| 三锯齿 / 三重横向(w-x-y-xx-z) | 5 |

切分方式：用细枢轴里"显著度最高的 k−1 个内部点"划分，每形态限 ~2 个切分变体（top-k 及近邻）。各候选按 §4 字典序排名。

### 5.2 文法约束（Q2 核心，"级别涌现"的机制）
父浪约束子浪的**可选假设集**：
- 推动浪的 **1/3/5**、锯齿的 **a/c** → 只允许**驱动类**假设（推动 / 引导楔形 / 终结楔形）。
- 推动浪的 **2/4**、锯齿的 **b** → 只允许**调整类**假设（锯齿 / 平台 / 三角 / 联合形）。
- 平台形的 a/b=调整类，c=驱动类；三角形各腿=调整类；联合形 w/y/z=调整类、x/xx=调整连接。

### 5.3 beam + 剪枝（Q12=a）
每节点按字典序保留 **top-3** 拆解，其余剪掉；分支因子被"形态种类 × ~2 切分变体"限住，不随枢轴数指数膨胀。硬规则失败不直接杀（Q3=b），但重罚降序。top-3 与 Q1"每节点挂 2–3 备选"对齐。

### 5.4 终止（Q7=a 数据驱动停）
一条腿的内部细枢轴 ≤3 个、拆不出合法子结构，即停，标"末级 / 不可再分"。深度由数据决定，不设固定层数。

## 6. 级别与枢轴（Q4=a 级别涌现）

引擎只吃**一套细枢轴**（`detectPivots(candles, 1)`）+ 复用 `anchorBoundaryExtremes` 给最大级别起点/进行中末端锚极值。"级别"= 拆解深度的涌现结果，非预设参数 → 从根上消解「顶点丢失 / 进行中腿不显示 / 坍腿」三症状。

## 7. 进行中浪（Q9=a 完成度 + 预期）

每级别最后一浪：
```
status: 进行中(第 X 浪 / 共需 Y 浪)
已满足 / 未满足哪些规则
expectation: { 下一浪方向, 斐波目标区间, 通道目标 }   // 明确标注为推断，非确定
```
已完成的兄弟浪正常定稿。衰竭/失败浪由 `computeMeasures` 的 price vs gross 识别，作为一种可命名状态。

## 8. 书中知识 → 架构归属（定位修正 + Q15–Q18）

| 书中知识 | 归属 |
|---|---|
| 形态 + 硬规则 | 闸门 tier1–2 |
| 指引（倾向） | 打分 tier3 |
| 斐波·价格（验证） | 打分 tier3 |
| 斐波·价格（目标） | **投影层**（驱动 Q9，不评分） |
| 斐波·时间（共振） | tier4 + 注记 |
| 通道（判别） | tier4 |
| 通道（完成 / 目标） | **投影层**（驱动 Q9，不评分） |
| 交替原则 | tier4 |
| 浪个性·价格形态（3浪最强/5浪背离） | **tier4**（Q15=b，仅平局裁决） |
| 浪个性·量能（volume） | **仅注记**（Q16=b，不参与排序） |
| 动量 / 背离 | **书外排除**（Q17=b） |
| 衰竭 / 失败浪 | 状态识别（§7） |
| 级别 / 分形 / 标注 | 涌现（§6） |

> 这些是新增的**判断维度**，不是新**形态**，故不违反"冻结形态清单"。

## 10. 输出 schema（Q13=a）

console / Markdown / JSON 三件套。计数树节点：
```js
{
  degree,                      // 涌现的拆解深度
  label,                       // 形态名
  direction,                   // up | down
  points,                      // 边界枢轴
  waveIndexInParent,           // 在父浪中的序号(1/2/3/a/b/w/x…)
  fitScore: { violations, overshootSum, guidelineHits, crossDegreeHits, penalized },
  status,                      // 完成 | 进行中
  expectation,                 // { nextDir, fibTargets, channelTargets }  仅进行中
  children: [],                // 子浪(递归)
  alternates: []               // 该节点 top-3 的其余备选
}
```
Markdown 把主链**自顶向下缩进**渲染为"大级别 → 当前浪"。
