# wave-channels

## ADDED Requirements

### Requirement: 三类艾略特通道
系统 SHALL 支持平行（3 点）、收缩（4 点）、扩散（4 点）三类艾略特通道，并按浪型选择通道类型：平行用于推动浪/单锯齿/平台形/双三锯齿/双三重横向整理；收缩用于引导楔形/终结楔形/收缩三角形；扩散用于扩散平台形。通道 SHALL 以算术坐标构建。

#### Scenario: 收缩三角形使用收缩通道
- **WHEN** 为收缩三角形构建通道
- **THEN** 连 b、d 终点为一线、a、c 终点为一线，形成向远处收缩的 4 点通道

### Requirement: 通道用规定子浪拐点构建
系统 SHALL 用每种浪型指定的子浪起/终点连线构建其通道（如平台形/单锯齿：前两点取 0 与 b、第三点取 a）。

#### Scenario: 单锯齿平行通道
- **WHEN** 已知单锯齿 0、a、b 三点
- **THEN** 引擎用 0 与 b 连线、过 a 作平行线，得平行通道；c 到达 a 的 1 倍时正好触通道边缘

### Requirement: 通道用于完成判定与拐点预测
系统 SHALL 提供两种通道作用：价格有效流出当前通道时提示"上一浪型可能已完成"（Guideline）；用通道边缘预测下一拐点的价格/时间位置（辅助，非确定）。

#### Scenario: 跌破推动浪下轨提示完成
- **WHEN** 一段被假设为推动浪的走势在满足内部结构后跌破其平行通道下轨
- **THEN** 引擎输出"该推动浪可能已完成"的提示
