# wave-degree

## ADDED Requirements

### Requirement: 级别标注与嵌套
系统 SHALL 为识别出的浪型标注级别（0/1/2… 数值越大级别越低），一个浪型的各子浪为同级（兄弟），高一级与低一级为父子关系；同一浪型内子浪级别一致。

#### Scenario: 子浪与父浪级别关系
- **WHEN** 一个 n 级推动浪被识别
- **THEN** 其 1-2-3-4-5 子浪标注为 n+1 级，且该完整推动浪可作为某 n-1 级浪型的一个子浪

### Requirement: 从高到低的跨级验证顺序
系统 SHALL 按"从最高级别到最低级别"（月→周→日→…）的顺序做浪型划分与验证；某一级验证不通过时返回上一步修正，而非从最低级别起数。

#### Scenario: 高级别不通过则回退修正
- **WHEN** 周线级别的浪型假设无法通过验证手册
- **THEN** 引擎回退并修正该级别假设，而非直接下探到更低级别

### Requirement: 低级别轻微不符可酌情忽略
系统 SHALL 允许在高级别已高度吻合手册时，对最低级别的轻微不符按书 3.23 酌情忽略，并在报告中标明该忽略。

#### Scenario: 大级别吻合而最小级别微差
- **WHEN** 从大级别逐级下降均满足手册，仅最小级别有个别条款轻微不符
- **THEN** 引擎保留该计数并在报告注明"最小级别轻微不符已按 3.23 忽略"
