# 提案：当前高点回撤叙述（current pullback narrative）

## Why

引擎已能拆出"进行中结构"里的 `currentPullback`（最近摆动高点 → 今），但报告对这段**只吐几个斐波
目标价**，没有可读的成句研判。用户要的是像人工点评那样的一段话：**这段回撤是什么级别、内部像什么
形态（可多选）、守住哪条线还能涨、最后一跌（Z 浪）会怎么走、跌到哪、走完后转向**——目前引擎有素材
却不成句。

关键卡点已在探讨中查清并有据可依：

- 1d 级别下这段回撤常常**只有 3 个枢轴**（如 79500→75538→今），拆不出可命名的调整形态
  （形态最少需 4 点）；但**下钻到子级别（4h）即有 10 个枢轴**，竞争形态排得出（已验证）。
- 用户的联合形读法（"XX 吃掉 Y 浪 70%"）**命中引擎既有文法** `xx须回撤y浪运行总量的70%`
  （实测 75.3%），非主观臆断。
- Z 浪目标（如 74758）= **Y 浪低点 − 0.236×腿幅**，且与 **Z=W=Y 等长**共振，公式干净可复现
  （已验证，误差 <4）。

因此这是**一处新叙述 + 一处子级别下钻 + 一个 Z 浪投影函数**，绝大部分素材复用既有引擎能力。

## What Changes

对 `analyze-wave-tree.js`（其余文件零改动）：

1. **新增"当前高点回撤"叙述段**，进"现状研判"可读块（不改主计数树）。叙述含四要素：
   ①**级别**（相对同段历史回撤深度分布定级）②**竞争形态**（多选）③**续涨条件**（结构线）
   ④**联合形浪位读法 + Z 浪双路径与目标**。

2. **回撤拆不出时下钻子级别**：当 `currentPullback` 段在当前级别枢轴数 <4（拆不出形态）时，
   **自适应步降**（起点降一级到 4h；仍不足再降 1h）重取该回撤窗口的 K 线，在子级别上拆解。
   拆解结果 MUST 明确标注为"子级别"、只描述回撤内部，**MUST NOT** 混入主计数树（级别隔离）。

3. **回撤剥两截**：`高点→回撤真低点`（已走完，拆竞争形态）+ `真低点→今`（进行中反弹，不拆）。
   真低点作为**结构线/续涨条件**："守住其上方，回撤结构未坏，仍有动力"。

4. **竞争形态多选**：复用 `decompose` 的 `primary + alternates`，**滤除 severe/文法违规**的候选，
   列出干净候选（给出"平台形或联合形"式的多可能读法）。

5. **联合形浪位读法**：当子级别拆为联合形（W-X-Y / w-x-y-xx-z）时，MUST 逐腿标注 W/X/Y/XX/Z
   起止，并给出 **XX 对 Y 浪的回撤百分比**（复用既有 70% 门槛判据）。

6. **Z 浪双路径投影（新计算）**：新增 `zwaveProjection()`（架构同既有 `bounceHypotheses`）：
   - **跌破路径**：破真低点后，主目标 = **Z=W=Y 等长带**（含 Y低−0.236×腿幅的破位档），
     延伸档 = XX高−1.272×Y、Y低−0.618×Y 等，输出**完整目标阶梯**。
   - **三角收缩路径**：用既有收缩三角文法判定是否成立（横向收敛，无单一价目标）。
   - 两路 **Z 浪走完后转向上涨**。

7. **"小级别"量化口径（新计算）**：用同段历史高→低回撤深度样本的**中位数**为界，回撤深度
   ≤ 中位数 → 判"小级别回撤"，否则按相对档位描述。

8. **叙述深度分层**：正文给"主目标 + 延伸档"精炼成句；**完整目标阶梯入 JSON** 备查。

9. **JSON 序列化扩展**：在 `inProgressTree.currentPullback` 下新增 `subDegree`、
   `combinationReading`、`structureLine`、`zwaveTargets` 字段，与主树**平级隔离**。

## Capabilities

### New Capabilities
- `current-pullback-narrative`: 当前高点回撤的可读叙述能力——子级别下钻拆解、竞争形态多选、
  "小级别"历史分位定级、联合形浪位读法、Z 浪双路径与完整目标阶梯投影。

### Modified Capabilities
- `wave-count-tree`: `inProgressTree.currentPullback` 的 JSON 结构扩展（新增 subDegree /
  combinationReading / structureLine / zwaveTargets 字段），并在现状研判块渲染回撤叙述。

## Impact

- 改动文件：`analyze-wave-tree.js`（回撤叙述渲染、子级别下钻取数、Z 浪投影函数、历史回撤分位、
  currentPullback JSON 扩展）。
- 涉及能力：`current-pullback-narrative`（新）、`wave-count-tree`（回撤段序列化 + 渲染）。
- 复用（不新写）：`decompose`（竞争形态 primary+alternates）、收缩三角文法、70% 联合形门槛、
  `bounceHypotheses` 架构、历史回撤样本计算、`fetchCandles/detectPivots`（子级别取数）。
- 不改：数据源、主计数树逻辑、既有报告与结构化报告、`analyze-kline-wave.js`。
- 兼容：叙述为新增输出；子级别下钻另起独立取数与 cache，不污染主级别分析。

## 非目标

- **不做警戒线/预警**：不实现"跌破 X 提高警惕"这类阈值预警（用户明确暂不需要）；结构线 75538
  仅作续涨条件与拆段依据，非预警功能。
- **不追具体历史手记数字**：如 75028 无干净公式，不写死凑出来的比率制造假精度。
- **不混级别**：子级别拆解只服务回撤叙述，MUST NOT 进入或改写主计数树（级别卫生）。
- **不引入书外指标**：级别/形态判定只用书内结构与斐波比例，不引入动量/RSI。
- **不给统计概率**：目标位给依据与相对概率语义（主/延伸/极端），不给百分比概率。
