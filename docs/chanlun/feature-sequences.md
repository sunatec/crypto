# 线段特征序列实现记录

日期：2026-11-01。任务4.4的共享处理器与研究适配器已实现；两类S终结、候选后缀重建与橙色线段已接入研究入口，4.5–4.7的实际Pine核对仍待执行。详见segment-engine.md。

`ChanFeatureSequence`消费已锁定笔。向上段选向下笔，向下段选向上笔；其他笔仅推进输入身份。标准元素保存有序来源笔ID、起止跨度、各极值来源时间、最晚证据时间和分界两侧身份。处理后元素封口与线段确认是两种状态。

包含方向来自已知非包含上下文；同类包含继续顺序处理，不把原始相邻包含当成传递关系。相等极值保留更早来源。第一序列不跨假设分界合并，第二序列没有此豁免；方向不足时保留未决笔并等待带证据上下文重建。预算不足时停止，不能通过丢掉必要来源继续推进。工程约定见E-006。

`chan_segment_seed`核对三笔交替、连续时价端点、顺序、确认因果、价格方向及公共区间；只有三笔数量不构成合规起始。`chan_feature_turn`只提供所需顶／底、来源与缺口诊断，不产生段完成事件。

## 独立样例

所有数值是手工推导的合成输入，不是原图精确行情。每个输入前缀均列出标准元素、成员来源、极值时间和状态。

| 样例后缀（统一前缀S-FEATURE-） | 核对内容 |
| --- | --- |
| UP／DOWN | 按段方向过滤；特征顶／底 |
| UP-INCLUSION／DOWN-INCLUSION | 顺序包含，双较高／双较低及来源替换 |
| EQUAL-ORIGIN | 价格相等时保留更早来源 |
| FIRST-BOUNDARY／SECOND-BOUNDARY | 相同笔流在第一／第二序列中的不同跨界行为 |
| WAIT-DIRECTION | 首次包含缺方向时保留未决输入，不能猜测 |
| ELEMENT-LIMIT／SOURCE-LIMIT | 分别限制标准元素数和全部来源数；停止后状态不再推进 |
| GAP／TOUCH | 严格缺口与闭区间接触分别记录；不触发正式段确认 |
| NO-START | 三笔无公共重叠，起始资格不成立 |
| 81-LOWER／81-EQUAL／81-HIGHER | 第81课第二序列必须处理包含的三种对应关系 |

第81课样例仅截取从原高点开始的反向候选B，固定端点为`18→12→16→10→h→12→20`，其中`h=15/16/17`分别对应图中7低于／等于／高于5。低于时三个上行特征区间为`[12,16]、[10,15]、[12,20]`，有底分型；相等／更高时，前两元素包含后为`[10,16]`，加最后元素也只有两个标准元素，没有该底分型。原图完整A/B/C归属尚未由这个局部驱动断言。

## 共享验证与研究绘图
