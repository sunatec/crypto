## 计算与提交

正式S输入是P模块锁定事件，开关不参与计算。初始化寻找最早合法三笔；之后保留未完成笔事实，对每个合规奇数笔端点分别建立转折假设。特征序列使用该假设的显式方向上下文，初始化与同批提交选择见E-007。

第一破坏笔仍有效时，其方向约束覆盖未确认后缀。按端点先后核验，处理完该上下文的证明后停止枚举其内部后移假设，不能用内部笔另起一个较小破坏范围绕过等待。先破起点使旧假设失效时解除约束；取得证明时先提交该段再推进子后缀。此约束不是对真实段起点添加全段极值条件。

第一类包括第71课第一破坏笔直接从转折点出发的分支，以及标准特征分型无缺口的分支；第三笔仍在第一破坏笔范围内时等待，严格先破结束位置才推进，先破起点则该假设失效。第二类等待实际反向第二序列分型，不额外要求补原缺口，也不再递归区分第二序列两类。第81课同一输入既构成第二序列证明又创新高时，先完整核对证明，再判断失效。

转移在独立副本执行。确认事件是一批只读段记录，发生时间和确认时间分别保存；第二类可同批锁定旧段与反向段。未确认假设由保留笔事实重建，已锁定前缀不参与撤销。续部从刚确认端点开始；迟到归属释放保留父段依赖。成员端点极值摘要只统计归属笔，证明所用的外部笔不会扩进段范围。

默认最多保留64条未完成笔，可设16～128；另有探查工作预算。超限会撤回本输入整批拟确认、保留原前缀和未消费输入，并停止S上报，面板区分依赖数和计算预算受限。该界限是资源限制，不是成段阈值。实际5000根及实时性能仍待平台验证。

未收盘K/F/P推演只能驱动S独立副本。候选段及该副本产生的拟确认事件均画虚线；正式收盘提交的S事件才画实线。研究模式可显示第一／第二特征序列、缺口、确认时刻和依赖。图形回收不会修改S计算状态。

## 同一内核的独立预期

下表均是合成已锁定笔输入；预期经过人工推导。当前S12修正版全套由用户报告PASS，覆盖下表及预算停止检查；不扩展为行情、K/F/P全套或递归通过。

| 样例 | 预期确认 |
| --- | --- |
| S-FIRST-END | 前缀6锁定旧段 |
| S-FIRST-CONTINUE | 先破起点，不提交旧结束点 |
| S-FIRST-WAIT-END | 前缀6仍等待，前缀8锁定 |
| S-FIRST-WAIT-INCLUSION | 标准包含产生看似分型，前缀8仍禁止提前锁定，到前缀10才锁定 |
| S-WAIT-DIRECTION-INSIDE | 首个反向笔未被严格突破前，包含分型不能代替方向证明 |
| S-SPECIAL-INTERNAL-EXTREME | 原段起点10、内部高点12分别保留；外部证明15不进入原段范围 |
| S-FIRST-EQUAL-THIRD | 相等不算严格突破，保持候选 |
| S-FIRST-LOCKED-PREFIX | 前缀6／9／12各确认一段，既有记录只读 |
| S-START-AFTER-INVALID | 跳过最初不合规起始，在前缀7确认后来的合法首段 |
| S81-LOWER | 前缀9同批确认A、B，不要求补原缺口 |
| S81-EQUAL／HIGHER | 包含后无所需第二分型，不伪造A、B确认 |

`tools/chanlun/segment-validation.mjs`生成对生产内核的调用，检查每个前缀的稳定ID、端点、方向、依赖、事件、原状态不变、重载、去重和深复制隔离。持有已确认事件原引用，以便后续修改被断言发现。成员极值用归属区间内所有源端点的界限和来源见证核对。另有工作预算整批停止及依赖数上限检查。

生成命令：

```powershell
node tools/chanlun/build-segment-compact.mjs
```

先运行`tmp/chanlun/segment-compact/smoke.pine`，单例10前缀，需要10根已收盘图表K线；通过后再运行`all-cases.pine`，12例110前缀及预算检查，需要111根已收盘K线。`cases/`另有12个独立样例。精简驱动仍持有确认事件原引用，以共享函数检查相同预期；每根图表K线推进一个前缀，不消费图表价格。两者提取同一CORE并记录哈希。显示PASS才是对应Pine断言通过；生成文件和本地Node测试均不算Pine执行。展开版由`build-validation.mjs`继续生成供对照，超时反馈与范围见[记录](compiler-timeout.md)。
