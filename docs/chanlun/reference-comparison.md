## 公开说明的功能范围

作者介绍包含实时结构画线、中枢、多层分析、三类买卖点、可配置结构规则与警报；另说明端点数值可表达MACD面积。以上是发布者描述，本次没有逐项运行验证。公开页同时写有试用范围及PRO授权提示，不据平台通用“可使用”文案推断BTC/ETH权限。

## 对本项目的具体取舍

以下为本项目的设计建议／既定范围映射，不是竞品已验证行为：

| 项目 | 本次参考结论 |
| --- | --- |
| 笔、线段、走势 | 维持设计中蓝笔、橙段、各层走势可区分的方案，采用统一视觉层次；还未实现的结构不能先画近似线填充画面 |
| 同层对象 | 走势线、中枢边界、标签使用同层色系；中枢填充更浅 |
| 线型 | 保留本项目已确认实线／候选虚线契约。静态预览不足以核实竞品是否这样处理 |
| 编号 | 可参考编号定位和字号控制；首版使用结构ID／确认信息，不把竞品买卖点圈号照搬为交易信号 |
| 默认视图 | 优先展示近期笔、段、中枢及走势；规则ID、包含跨度、特征序列放研究开关内 |
| MACD、买卖点、提醒 | 按现提案留待后续变更，本次仅记功能参考 |
| 多规则模式 | 不复制LOOSE/STRICT等模式；继续采用一套可追溯规则 |
| 层级 | 继续用L1–L3表示结构关系，不直接换算成固定时间周期 |

## 提案中的落实方式

本参考已纳入变更 `rebuild-chanlun-tradingview-indicator` 的 proposal、design 和平台规格，具体实现与验证由任务7.4和8.6跟踪。主要映射为：默认蓝笔、橙段、紫色L1及可区分的L2/L3；同层走势、正式中枢和标签同色系；笔线较细、上层逐级突出；浅色中枢保持K线可读；字号、线宽、颜色及中枢透明度可调。

走势类型文字须来自内核判定，结构编号采用可区分的类型/层级标识。静态图中圈号只提供定位和密度参考，不能直接当作确认状态或已实现交易信号。普通和研究视图分别保留渲染证据。MACD面积、背驰、三类买卖点和提醒沿用既定后续阶段；多规则模式仅记录其存在，不纳入首版。

静态图无法验证笔段划分是否遵守选定原文、递归完成条件、候选的撤销方式、确认事件时刻、重载一致性及计算资源表现。后续实测需记录具体版本／设置、feed、时间窗口、OHLC和观察证据。本次资料不计作TradingView编译或回放验收通过，也不使任务7.3整体完成。
