# L1中枢：形成、回试与连续中枢关系

2026-11-04。任务5.2的Z7及首个中枢入口已有用户报告通过；本轮5.3连续中枢Z13已由用户报告13组91前缀全套PASS；正式入口也由用户报告“连续中枢入口正常”。走势完成属于5.4，不因中枢形成或离开而成立。

来源为C18-39的三个已完成部件完整交集、C18-40的离开／回试区分，以及C20-43（PDF第42–44页）的延伸、新生和GG/G/D/DD比较。N采用独立区间，形成核验保留三个区间，不套用依赖相邻分析价格相等的A/C简式。仅消费生产N确认事件；预览不提交，也不发送R完成事件或L2输入。

| 状态 | 行为 |
| --- | --- |
| 不足三个／没有公共区间 | 保留最近两个部件，等待下一连续部件 |
| 三个区间交集非空 | 形成下一个L1中枢，固定核心、形成时刻、三来源及累计编号 |
| 当前真实终点在核心外 | 暂存离开部件，不立即结束中枢，也不提前计入未定归属的波动 |
| 下一部件实际范围触及核心 | 离开部件归原中枢；再判断本部件是否成为下一离开候选 |
| 下一部件实际范围严格在核心外 | 确认原中枢离开，单列离开／回试证据；从回试部件开始寻找下一个三部件交集 |
| 新中枢形成／延伸 | 比较与前一已关闭中枢的固定核心及波动包络，更新当前关系证据 |
| 任一来源提交超过预算 | 整个当前输入回滚，保留原结果、待定离开及未消费输入，停止本层 |

待定归属是E-010的有限工程约定，不声称作者给出了唯一的软件分段算法。真实终点用于识别离开候选，回试用自身实际区间判断，不能把N的分析极值时间冒充真实连接点。形成第三部件是必要来源，即使它也成为离开候选，仍保留在形成记录；重复归属检查避免二次统计。其余尚未归属的连接部件不混入旧中枢成员或GG/DD，离开证明独立保存。

只有与形成方向相同的Z波动更新GG=max(gn)、G=min(gn)、D=max(dn)、DD=min(dn)。反向部件可以归属并推进extent，但不改变这四个统计。固定核心与形成时刻不变；形成事件是当时快照，关闭事件是最终归属快照，两者原引用以后均不改写。

例如A5→10、B10→8、C8→11形成[8,10]；D11→7之后，E7→20暂存。如果F20→9触及核心，E纳入，GG更新至20。如果F20→14完全在核心外，E作为连接证据，旧GG仍11；随后G14→22、H22→15形成[15,20]，其DD14>旧GG11，得到上移延续证据。

| 当前关系证据 | 条件 |
| --- | --- |
| up-continuation | 后DD>前GG |
| down-continuation | 后GG<前DD |
| range-overlap | 核心严格分离、波动包络接触或重叠：扩展证据 |
| core-overlap | 核心未严格分离，保留证据，待后续结构规则核验 |

关系是当前快照，可以随新中枢继续纳入Z波动而变化。Z-RELATION-EVOLVES先有上移证据，后因新DD下降转为波动重叠；这不会修改已确认核心、形成事件或已关闭中枢，也不表示已确认R走势被替换。当前不创建高级别完成输入或宣称整个趋势完成。
