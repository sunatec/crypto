## 完成前必须补齐的可审查材料

1. **可执行输入**：背驰路径须区分背驰概念、辅助MACD、实际成立与潜在背驰段。若选择不依赖背驰的结构路径，必须明确自己的替代充分证据及来源／工程约定；不能悄悄删除C43／C88的前提。
2. **确立谓词**：把C88的新走势类型确立写成只用当前已确认低层输入的有限条件；明确适用层级、方向、中心数、延续及扩展排除条件，不直接引用待证明的R完成事件。
3. **成员和边界**：每一完成分支固定子对象集合、真实／分析极值来源、端点发生时刻、确认时刻、新走势起点及允许的端点复用；用C99的尾部吸收与保留两分支检验。
4. **追加稳定性**：给出该守卫后允许的各类未来追加，并核对这些追加只发展可变尾部，不改变已发R的成员和端点。单个正例通过不能代替此项，亦不可要求观察无限未来后才确认。
5. **事件顺序与进展**：定义同批多事件的下层→本层→上层顺序、一次性消费和预算中止规则；不能让最高层完成成为低层完成的先决条件。
6. **独立预期**：至少覆盖同级别背驰的已成立／尚可能失效对照（如果选此路径）、新走势确立前后、继续延伸、反向走势、末中心扩展、C99吸收／保留、窗口结束不完成，以及同一前缀在线／重载一致性。原图缺少逐笔价格时应明确标成合成约束例。
