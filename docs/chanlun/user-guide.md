# 看盘与研究使用说明

本指标当前是形态研究预览，完整重建尚未交付。安装时将chanlun_original.pine完整复制为TradingView新指标，添加到普通K线图；报错请保留第一条完整文字及行号。实际版本与验收范围见validation.md。

## 图上结构

| 图形或编号 | 含义 |
| --- | --- |
| 蓝色P# | 笔结构编号；实线已按选定规则锁定，虚线是可变尾部 |
| 橙色S# | 标准特征序列确认的线段；候选段仍画虚线 |
| 灰色N0# | 研究视图的L0独立分析区间映射，每个确认S对应一个；不是另一种真实行情折线 |
| 紫色框L1-Z# | 以确认L0形成的中枢固定核心；零宽核心显示边界线 |
| F顶#／F底# | 分型结构身份，默认关闭 |
| E#及缺口说明 | 线段特征序列的研究诊断，不单独构成线段确认 |

L0、L1表示结构关系，不是分钟周期换算。实际行情入口尚未输出完成的L1走势线或L2／L3输入；紫色框出现不等于L1走势完成。结构编号、分型与中枢关系文字都不是买卖点或交易建议。

## 显示设置

“笔”“线段”分组各有显示、编号、颜色、线宽和编号间隔。间隔1显示每个可见确认结构的编号；间隔3显示#1、#4、#7等，候选仍保留提示。编号筛选不隐藏折线、不改变结构数量；旧图形回收后累计编号不会重新从1开始。

“L1中枢”分组分别控制框、编号、颜色、边框线宽和填充透明度。关闭编号保留框。中枢默认浅紫色和透明填充；线宽1～5，透明度75～100，100表示不填充但保留边框。提示字号可调至 8～24。分型、确认、合并和特征诊断标注的字号最高为 12，右上状态面板字号为 14～16。合并根数、特征序列和极值来源可悬停查看。

普通视图优先看笔、段和中枢。研究模式可打开近期合并K线范围、特征与缺口、确认时间和L0映射；悬浮标签查看规则、来源和时刻。合并K线框不是中枢。研究标签共用全局额度，默认最多120个；过密时先减少编号、关闭不需要的研究图层。

## 面板与定位

面板“确认线段”和“L0标准部件”正常应相等。“L1中枢”是累计形成数，可大于当前视口内框数或最近15个可见历史中枢数量。通过最近中枢时间与价格行定位框所在的历史区域，不能据数量认定当前价格附近必有框。

固定核心可随新部件延长时间范围，核心价格不不断收窄。上移／下移延续或波动重叠是当前关系证据，可随后续波动改变；不是不可撤销的走势完成信号。离开待定、历史不足、样本截断、预算受限和R规则未闭合各有不同含义，见resource-status.md。

## 分析范围与复现

近期模式默认从加载时最近5,000根开始，运行中新K线继续原状态；重载时加载锚点可能改变。固定起点按K线开盘时间对齐；请求落在K线中间时从下一开盘开始。请求起点、实际接收起点和有效种子起点可能不同，初始化包含链会影响有效种子。

固定模式达到样本上限后停止接收，保留旧结果，不滚动重新分段。“样本上限已达”表示名额用完；“样本已截断”表示已有后续收盘K线被拒绝。恢复日常看盘可取消“使用固定起点”。固定起点100根截断已由用户报告验证通过，详情见analysis-window.md。

比较在线、回放和重载时须使用相同feed、普通K线、周期、UTC起止、规则版本、参数和OHLC。不同交易所数据不可混作同源结果；当前仍未完成BTC／ETH的60、240、D六组合固定行情验收。候选端点可以变化，确认时间晚于发生时间，不能把指向过去端点的图形当成当时已有的确认。

## 买卖点与背驰信号（信号阶段）

**验证状态（2026-11-13）**：背驰与买卖点的判定在 TradingView 通过了同核验证脚本（19 个独立样例、154 个前缀，见[信号阶段验证](signal-validation.md)）；正式指标已在平台加载并运行。图上标记的实图归档和提醒的实时验证还没有完成，见 signal-validation.md 第 6 组，使用前请先看那里的状态。

### 图上标记的含义

买卖点标记是**实心**的带箭头小标签，文字为“层级＋类型＋买／卖”；买点在价格下方向上指，卖点在价格上方向下指，颜色可在设置里改。它和结构编号一眼可分：笔、线段、中枢的 P#、S#、L1-Z# 只有彩色文字，没有底色，也不带“买”“卖”字。

| 标记文字 | 含义 | 规则 |
| --- | --- | --- |
| L1 一买／一卖 | 第一类买卖点：同层趋势背驰的离开段端点，离开段已确认时提交，不等回抽 | D-001、D-002、B-001 |
| L1 盘背买／盘背卖 | 盘整背驰点：只有一个中枢时，离开段与同向进入段比较；**不是第一类买卖点** | D-001、D-003、B-004 |
| L1 二买／二卖 | 第二类买卖点：第一类之后，再出现第二个同向部件，其端点不越过第一类价格（相等不算越过） | B-002 |
| L1 三买／三卖 | 第三类买卖点：中枢关闭时的回抽部件端点；回抽恰好触及中枢边界仍算回到中枢，不出信号 | B-003、E-010 |

L1、L2、L3 是结构层级，不是分钟周期换算。同一端点同时有结构编号和买卖点时，两个标签并存；悬浮标签可看信号 ID、规则、发生与确认时间、依赖的结构 ID。

- **面积与比较**：MACD 按图表周期和“MACD（信号阶段）”分组的快、慢、信号参数（默认 12、26、9）计算，面积只在同层、同参数下做相对比较（M-001～M-003）。这是工程约定，不是原文规定的唯一口径；原文也说明 MACD 辅助“不精确”。面积所在的数据已被回收或仍在预热时，该比较记为“面积不可用”，不出信号。
- **创新高（低）是硬条件**：离开段终点要严格越过比较段的范围极值（相等不算），面积要严格更小。黄白线是否回拉零轴只做研究参考，不影响信号。
- **不可更改**：信号确认后只追加、不移动、不删除；重载或重复执行同一根 K 线不会产生重复信号。

### 设置

“买卖点（信号阶段）”分组：

- “启用背驰与买卖点（关闭则不计算）”：关闭后 MACD、信号和候选都不计算，形态结构的结果与确认历史与开启时完全一致。
- “显示确认买卖点”、L1／L2／L3 三个层级开关、第一类／盘整背驰点／第二类／第三类四个类型开关、买点和卖点颜色。层级开关与类型开关都打开的信号才画出；这些开关只决定画不画，不改变计算。
- 标记计入全局标签预算（“全局研究标签上限”）：买卖点标记最多保留最近约 30 个买点和 30 个卖点，预算吃紧时先让出其他标签，最后才让出买卖点标记。

研究视图（视图选“研究”）里另有：

- “研究：显示面积对比与比较段”：对每个背驰类信号画一条连接 A、C 两段端点极值的细线，中间标出“A面积／C面积”。
- “研究：显示未成立原因”（默认关）：灰色小字标出没有出信号的原因，如“终点没有严格创新高（低）”“面积不小于比较段”“越过第一类价格”“回抽触及中枢边界，算回到中枢”。它是记录，不是信号，不触发提醒。
- “研究：显示候选信号（实时预览，未收盘K线）”（默认关）：最后一根未收盘 K 线上，如果按当前假设的线段会形成信号，就画**空心**候选标记。收盘时条件不再成立，它就消失，不进入确认流，也不提醒。

尚未实现的研究信息（规则 D-004）：B 段期间黄白线回拉零轴、C 段黄白线极值是否超过 A、C 终点是否越过中枢已归属部件极值、信号提交后中枢的后续走向。区间套只在信号悬浮提示里写“可用低级别区间套细化”，没有请求低周期数据，也不做区间套定位。

### 提醒

“提醒（信号阶段）”分组默认关闭。勾选“启用提醒”，再选要提醒的层级和类型。TradingView 里这样建提醒：

1. 在图上打开“创建提醒”。
2. “条件”选本指标，下方选“任何 alert() 函数调用”。
3. 通知方式按需选择，消息框保持默认即可，实际文字由指标给出。

消息格式：`缠论买卖点 <品种> <周期> L<层级> <类型><买点／卖点> 价格 <价格> 发生 <时间> UTC 确认 <时间> UTC ID <信号ID>`。

- 只在**实时行情**里已确认信号所在 K 线收盘时触发；历史 K 线、未收盘的候选、“未成立”记录都不触发。
- 同一根 K 线确认多个信号时，每个通过开关的信号各发一条；某信号被层级或类型开关挡掉则不发。
- TradingView 的提醒保存的是创建时的设置。改了开关或参数后，请删除旧提醒再新建。
- 修改 MACD 参数会让全部面积和背驰重算，形态结构不受影响。
