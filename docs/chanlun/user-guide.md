# 看盘与研究使用说明

本指标当前是形态研究预览，完整重建尚未交付。安装时将chanlun_original.pine完整复制为TradingView新指标，添加到普通K线图；报错请保留第一条完整文字及行号。实际版本与验收范围见validation.md。

## 图上结构

| 图形或编号 | 含义 |
| --- | --- |
| 蓝色P# | 笔结构编号；实线已按选定规则锁定，虚线是可变尾部 |
| 橙色S# | 标准特征序列确认的线段；候选段仍画虚线 |
| 灰色N0# | 研究视图的L0独立分析区间映射，每个确认S对应一个；不是另一种真实行情折线 |
| 紫色框L1-Z# | 以确认L0形成的中枢固定核心；零宽核心显示边界线 |
| F顶#／F底# | 分型结构身份，默认关闭 |
| E#及缺口说明 | 线段特征序列的研究诊断，不单独构成线段确认 |

L0、L1表示结构关系，不是分钟周期换算。实际行情入口尚未输出完成的L1走势线或L2／L3输入；紫色框出现不等于L1走势完成。结构编号、分型与中枢关系文字都不是买卖点或交易建议。

## 显示设置

“笔”“线段”分组各有显示、编号、颜色、线宽和编号间隔。间隔1显示每个可见确认结构的编号；间隔3显示#1、#4、#7等，候选仍保留提示。编号筛选不隐藏折线、不改变结构数量；旧图形回收后累计编号不会重新从1开始。

“L1中枢”分组分别控制框、编号、颜色、边框线宽和填充透明度。关闭编号保留框。中枢默认浅紫色和透明填充；线宽1～5，透明度75～100，100表示不填充但保留边框。提示字号可调至 8～24。分型、确认、合并和特征诊断标注的字号最高为 12，右上状态面板字号为 14～16。合并根数、特征序列和极值来源可悬停查看。

普通视图优先看笔、段和中枢。研究模式可打开近期合并K线范围、特征与缺口、确认时间和L0映射；悬浮标签查看规则、来源和时刻。合并K线框不是中枢。研究标签共用全局额度，默认最多120个；过密时先减少编号、关闭不需要的研究图层。

## 面板与定位

面板“确认线段”和“L0标准部件”正常应相等。“L1中枢”是累计形成数，可大于当前视口内框数或最近15个可见历史中枢数量。通过最近中枢时间与价格行定位框所在的历史区域，不能据数量认定当前价格附近必有框。

固定核心可随新部件延长时间范围，核心价格不不断收窄。上移／下移延续或波动重叠是当前关系证据，可随后续波动改变；不是不可撤销的走势完成信号。离开待定、历史不足、样本截断、预算受限和R规则未闭合各有不同含义，见resource-status.md。

## 分析范围与复现

近期模式默认从加载时最近5,000根开始，运行中新K线继续原状态；重载时加载锚点可能改变。固定起点按K线开盘时间对齐；请求落在K线中间时从下一开盘开始。请求起点、实际接收起点和有效种子起点可能不同，初始化包含链会影响有效种子。

固定模式达到样本上限后停止接收，保留旧结果，不滚动重新分段。“样本上限已达”表示名额用完；“样本已截断”表示已有后续收盘K线被拒绝。恢复日常看盘可取消“使用固定起点”。固定起点100根截断已由用户报告验证通过，详情见analysis-window.md。

比较在线、回放和重载时须使用相同feed、普通K线、周期、UTC起止、规则版本、参数和OHLC。不同交易所数据不可混作同源结果；当前仍未完成BTC／ETH的60、240、D六组合固定行情验收。候选端点可以变化，确认时间晚于发生时间，不能把指向过去端点的图形当成当时已有的确认。
